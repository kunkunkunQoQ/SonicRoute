Слушайте музыку через колонки, а игры и звонки — в наушниках. SonicRoute — аудиопрограмма для Windows, работающая в области уведомлений: выбирайте устройства вывода и ввода для отдельных приложений, управляйте звуком с помощью горячих клавиш, прокрутки в области уведомлений или панели и объединяйте повторяющиеся действия в правила автоматизации.

## ✨ Возможности SonicRoute

<a href="https://github.com/kunkunkunQoQ/SonicRoute/wiki/02-%E5%8A%9F%E8%83%BD%E7%89%B9%E6%80%A7" title="Возможности"><img src="docs/images/mascot-music-hoodie.png" width="68" align="right" alt="Нажмите на маскота, чтобы узнать о возможностях SonicRoute"></a>

- **Автоматическое определение активного приложения.** По умолчанию управление следует за аудиоприложением, которым вы пользуетесь. При закрытой панели одни и те же горячие клавиши меняют его громкость и устройства или отключают звук. Колёсико в области уведомлений тоже регулирует его громкость — искать приложение в списке не нужно.
- **Быстрая панель.** Нажмите значок в области уведомлений, чтобы управлять громкостью приложений в одном месте. Нажмите значок приложения для отключения звука или разверните раздел устройств и выберите наушники либо колонки. Музыкальный плеер, игра и приложение голосового чата регулируются отдельно.
- **Правила автоматизации.** Расставляйте по порядку переключение устройств, настройку громкости, запуск программ и другие шаги; добавляйте задержки и запускайте правила горячей клавишей, при запуске приложения или переключении на него либо по расписанию. **Добавлено в разрабатываемой версии 1.25:** управление воспроизведением и записью на устройствах и в приложениях, пакетная настройка всех приложений, сброс маршрутов всех приложений, показ и скрытие быстрой панели.

## 🚀 Скачивание и начало работы

**Текущая версия: [v1.24](https://github.com/kunkunkunQoQ/SonicRoute/releases/tag/v1.24)** · 2026-10-20 · [Примечания к выпуску (на китайском)](docs/release-v1.24.md)

Для большинства компьютеров с Windows x64 версия из Microsoft Store обеспечивает удобную установку и автоматические обновления. Выберите Lite x64, если нужен один исполняемый файл, или Legacy x64, если установка .NET 8 неудобна. Ссылка для скачивания выше всегда ведёт на последнюю версию; прямые ссылки ниже относятся к выпуску v1.24.

| Вариант | Скачать | Требования |
|---|---|---|
| Lite x64 | [Один EXE-файл](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.24/SonicRoute-v1.24-Lite-x64.exe) | .NET 8 Desktop Runtime для x64 |
| Lite ARM64 (экспериментально) | [Один EXE-файл](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.24/SonicRoute-v1.24-Lite-arm64.exe) | .NET 8 Desktop Runtime для ARM64 |
| Legacy x64 | [Полный ZIP-архив](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.24/SonicRoute-v1.24-Legacy-x64.zip) | .NET Framework 4.8; перед запуском распакуйте архив целиком |
| Microsoft Store | [Установить из Store](https://apps.microsoft.com/detail/9NQZGRTPM1NT) | x64; автоматические обновления; доступная версия указана в Store |

Для Lite требуется соответствующая версия [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0). Для Legacy .NET 8 не нужен.

1. Запустите SonicRoute, найдите значок в области уведомлений Windows (он может находиться среди скрытых значков) и дважды щёлкните по нему, чтобы открыть полный интерфейс.
2. В настройках выберите нужные устройства вывода и ввода.
3. Нажмите значок в области уведомлений, чтобы открыть панель или настроить горячие клавиши. Если нужно объединить несколько действий, создайте правило автоматизации.

Перед первым использованием `sr` запустите SonicRoute обычным способом, чтобы зарегистрировать команду, затем откройте терминал заново. Если переключение устройств работает не так, как ожидалось, обратитесь к разделу [Частые вопросы](https://github.com/kunkunkunQoQ/SonicRoute/wiki/06-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98).

В версии 1.24 добавлены шаблоны автоматизации, подробный журнал последних выполнений (по умолчанию выключен, с настраиваемым лимитом хранения) и собственные значки приложений. Если значок отсутствует или используется стандартный, отображается первый символ названия приложения. Импортированные значки входят в резервную копию настроек. Предыдущие изменения: [История версий](https://github.com/kunkunkunQoQ/SonicRoute/wiki/09-%E7%89%88%E6%9C%AC%E5%8E%86%E5%8F%B2).
