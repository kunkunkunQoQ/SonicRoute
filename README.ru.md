## ✨ Возможности SonicRoute

- **Устройства воспроизведения и записи для каждого приложения.** Направьте музыку на колонки, а звук игры — в гарнитуру. Для голосового чата выберите микрофон гарнитуры. На быстрой панели удерживайте Ctrl для добавления или снятия устройств воспроизведения и Shift для выбора непрерывного диапазона; все редакции позволяют объединять несколько аудиовыходов ПК, а Full — добавлять и доступные выходы телефона. Windows запоминает выбранные устройства, даже если выйти из SonicRoute.
- **Управление из области уведомлений.** SonicRoute может выбирать приложение по активному окну. Прокрутите колёсико над значком программы, чтобы отрегулировать громкость этого приложения. Если удерживать Alt, прокрутка переключает его устройство вывода. Изменения видны на экранном индикаторе. Отдельное сочетание клавиш отключает звук всех микрофонов.
- **Быстрая панель с индикаторами уровня звука.** У каждого приложения есть свой регулятор громкости и индикатор, по которому видно, играет ли звук. Панель запоминает своё положение. Её высоту можно менять от 350 до 850 логических пикселей.
- **Android и AirPlay в редакции Full.** Слушайте звук Android-приложений на ПК, открывайте их на отдельных виртуальных экранах или передавайте звук с ПК на телефон. Для Android доступны видео H.265 и управление с геймпада в активном окне трансляции. Встроенный приёмник AirPlay на C# воспроизводит звук и показывает экран с сохранением пропорций. На быстрой панели можно направить звук на устройство вывода ПК, динамик телефона с Android или подключённое к нему Bluetooth-устройство. Умная регулировка громкости сглаживает громкие фрагменты в поддерживаемых потоках.
- **Правила автоматизации и командная строка.** Доступны 6 триггеров и 39 действий. Правило может сработать по сочетанию клавиш, по расписанию, при запуске SonicRoute, а также при открытии или закрытии приложения либо переключении на него. Объединяйте действия: переключайте устройства, меняйте громкость, отключайте звук, открывайте файлы и программы или запускайте PowerShell. Команда `sr` позволяет вызвать правило из скрипта или с аппаратного контроллера через уже запущенную SonicRoute.
- **Отслеживание системных событий.** SonicRoute получает уведомления Windows. При необходимости программа раз в секунду проверяет состояние процессов и освобождает данные, которые больше не нужны. Интерфейс всех редакций доступен на девяти языках. Lite и Legacy предназначены для работы со звуком на ПК.

## 🎮 На каждый день

Например, одно правило может при запуске игры переключить звук на гарнитуру и открыть голосовой чат. [Настроить автоматизацию](https://github.com/kunkunkunQoQ/SonicRoute/wiki/04-%E8%87%AA%E5%8A%A8%E5%8C%96%E8%A7%84%E5%88%99)

| Ситуация | Что можно сделать |
|---|---|
| 🎮 **Звук игры заглушает голосовой чат** | Отрегулируйте громкость голосового чата, например Discord, отдельно от игры. При желании направьте звук игры и чата на разные устройства. |
| 🎵 **Музыка или видео во время игры** | Направьте музыку на колонки, а игру — в гарнитуру. Прокруткой над значком SonicRoute можно менять громкость выбранного приложения, а с зажатой клавишей Alt — его устройство вывода. |
| ⚡ **Переход на гарнитуру при запуске игры** | Создайте правило, которое при запуске игры переключит звук на гарнитуру, установит громкость на 40 % и откроет голосовой чат. Второе правило может вернуть вывод на колонки при выходе из игры. |
| 🎙️ **Нужно отойти от компьютера или поговорить без микрофона** | По умолчанию Ctrl+Shift+N отключает и снова включает звук всех микрофонов. Включите постоянный экранный индикатор, чтобы видеть, когда звук отключён. |
| 📹 **Трансляция через OBS или запись видеоурока** | Направьте звук нужных приложений на отдельное физическое или виртуальное устройство вывода и выберите его в программе записи. Чат и уведомления оставьте на другом устройстве. |
| 📱 **Звук и приложения телефона на компьютере** | В Full можно слушать звук Android на ПК и работать с приложениями телефона на виртуальном экране. AirPlay позволяет принимать звук и изображение с устройств Apple. Для вывода звука на быстрой панели можно выбрать устройство ПК, динамик Android-телефона или подключённое к нему Bluetooth-устройство. |

### 🏁 Первые шаги

1. **Запустите SonicRoute.** Откройте EXE-файл, затем дважды щёлкните значок SonicRoute в области уведомлений, чтобы открыть главное окно. Если значок скрыт, его можно перетащить из меню скрытых значков на панель задач.
2. **Выберите устройства.** В настройках отметьте наушники и колонки, которые хотите видеть на быстрой панели. Щёлкните значок SonicRoute один раз, чтобы открыть панель. Разверните строку приложения и выберите для него устройство вывода. Ползунок в этой строке регулирует громкость.
3. **Попробуйте колёсико мыши.** Наведите указатель на значок SonicRoute и прокрутите колёсико, чтобы изменить громкость выбранного приложения. Удерживайте Alt для смены устройства вывода этого приложения или Shift для регулировки громкости устройства вывода по умолчанию. В настройках можно включить такое управление для всей области уведомлений.

### ⚡ Запуск правил из командной строки

Команда `sr` передаёт имя или идентификатор правила запущенной программе SonicRoute через именованный канал. Сначала запустите SonicRoute, чтобы команда стала доступна, затем закройте и снова откройте терминал. После этого `sr` можно вызывать из скриптов, AutoHotkey и Stream Deck. Если SonicRoute закрыта, команда вернёт ошибку. Подробнее см. в разделе «[Частые вопросы](https://github.com/kunkunkunQoQ/SonicRoute/wiki/06-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)».

### ❓ Частые вопросы

**Что происходит с выбранными устройствами и громкостью приложений после выхода из SonicRoute?**

Windows сохраняет выбранные для приложений устройства и громкость существующих аудиосеансов. Для работы горячих клавиш, управления из области уведомлений, автоматизации, передачи звука с телефона, трансляции экрана и синхронизации буфера обмена оставьте SonicRoute запущенной.

**Какая среда выполнения нужна для моей редакции?**

Для Full и Lite нужна среда .NET 10 Desktop Runtime той же архитектуры, что и сборка. Для редакций из Microsoft Store нужна версия среды для x64. Legacy использует .NET Framework 4.8. Прежние сборки на .NET 8 доступны в архиве и больше не обновляются.

**Как SonicRoute в фоновом режиме влияет на нагрузку процессора и заряд батареи?**

Программа отслеживает уведомления Windows, при необходимости раз в секунду проверяет состояние процессов и освобождает ненужные данные. Нагрузка на процессор и расход заряда зависят от системы и используемых функций.
