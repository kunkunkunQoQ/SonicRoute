### 🏁 Первые шаги

1. **Откройте SonicRoute.** Запустите скачанный EXE-файл. Если выбрали Legacy, сначала распакуйте ZIP-архив целиком. Двойной щелчок по значку SonicRoute в области уведомлений открывает главное окно.
2. **Выберите выход.** В настройках отметьте устройства, которые хотите видеть на быстрой панели. Щёлкните значок SonicRoute один раз, разверните строку приложения и выберите устройство воспроизведения.
3. **Попробуйте колёсико мыши.** Прокрутите его над значком SonicRoute, чтобы изменить громкость приложения. По умолчанию среди приложений с аудиосеансом приоритет у того, чьё окно сейчас на переднем плане или было там последним. Удерживайте Alt при прокрутке, чтобы сменить его выход, или Shift, чтобы изменить громкость устройства воспроизведения Windows по умолчанию.

## ✨ Возможности SonicRoute

- **Выбирайте устройства воспроизведения и записи для каждого приложения.** На быстрой панели и на странице «Приложения» Ctrl + щелчок добавляет или убирает устройство, Shift + щелчок сохраняет текущий выбор и добавляет диапазон, а Ctrl+Shift + щелчок выбирает или переключает устройство нативной маршрутизации. Все редакции поддерживают одновременное воспроизведение на нескольких выходах ПК, а Full — также на выходах подключённого телефона Android.
- **Регулируйте громкость приложений.** По индикаторам на быстрой панели видно, какое приложение сейчас звучит. Громкость можно изменить ползунком, а для текущего приложения — колёсиком мыши над значком SonicRoute. Горячая клавиша позволяет выключить или включить сразу все микрофоны.
- **Настройте автоматизацию.** Выберите из 6 триггеров и 39 действий те, которые нужны для вашего правила. Например, при запуске игры можно сменить устройство вывода и отрегулировать громкость. Сохранённые правила можно запускать из командной строки с помощью `sr`.
- **Используйте Android и AirPlay в редакции Full.** Слушайте звук приложений Android на ПК или передавайте звук с ПК на динамик телефона либо подключённое к нему Bluetooth-устройство. Приложения Android можно открывать на отдельных виртуальных экранах с поддержкой H.265. Через AirPlay можно принимать звук устройств Apple и видеть их экран с сохранением пропорций. Можно также просматривать общую память Android-устройства и передавать сразу несколько файлов в обе стороны.

### ⚡ Запуск правил из командной строки

Команда `sr` передаёт имя или идентификатор правила запущенной программе SonicRoute через именованный канал. Сначала запустите SonicRoute, чтобы команда стала доступна, затем закройте и снова откройте терминал. После этого `sr` можно вызывать из скриптов, AutoHotkey и Stream Deck. Если SonicRoute закрыта, команда вернёт ошибку. Подробнее см. в разделе «[Частые вопросы](https://github.com/kunkunkunQoQ/SonicRoute/wiki/06-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)».

## ❓ Частые вопросы

**Что происходит с выбранными устройствами и громкостью приложений после выхода из SonicRoute?**

Windows сохраняет основное устройство воспроизведения и устройство записи для каждого приложения, а также громкость действующих аудиосеансов. Оставьте SonicRoute запущенной для одновременного воспроизведения через несколько выходов, работы горячих клавиш, управления из области уведомлений, автоматизации, передачи звука между телефоном и ПК, трансляции экрана и синхронизации буфера обмена.

**Какая среда выполнения нужна для моей редакции?**

Для Full и Lite нужна среда .NET 10 Desktop Runtime той же архитектуры, что и сборка. Для редакций из Microsoft Store нужна версия среды для x64. Legacy использует .NET Framework 4.8. Прежние сборки на .NET 8 доступны в архиве и больше не обновляются.

**Как SonicRoute в фоновом режиме влияет на нагрузку процессора и заряд батареи?**

Программа отслеживает уведомления Windows, при необходимости раз в секунду проверяет состояние процессов и освобождает ненужные данные. Нагрузка на процессор и расход заряда зависят от системы и используемых функций.
