<a name="quick-start"></a>

### 🏁 Первые шаги

1. **Запустите SonicRoute.** Откройте EXE-файл редакции Full или Lite нужной архитектуры. Дважды щёлкните значок SonicRoute в области уведомлений, чтобы открыть главное окно.
2. **Выберите устройство воспроизведения.** В настройках отметьте нужные устройства. На странице «Приложения» выберите приложение и соедините его основной выход на схеме с нужным устройством. Для быстрого переключения щёлкните значок в области уведомлений и раскройте строку приложения на быстрой панели.
3. **Попробуйте колёсико мыши.** Прокрутите его над значком SonicRoute, чтобы изменить громкость приложения. По умолчанию среди приложений с аудиосеансом приоритет у того, чьё окно сейчас на переднем плане или было там последним. Удерживайте Alt при прокрутке, чтобы сменить его выход, или Shift, чтобы изменить громкость устройства воспроизведения Windows по умолчанию.

## ✨ Возможности SonicRoute

- **Выберите на быстрой панели, звук какого приложения нужно захватить.** Разверните строку приложения на ПК и, удерживая `Ctrl`, щёлкните по второму устройству воспроизведения. Звук этого приложения будет слышен на обоих устройствах. Щелчок с Shift добавляет диапазон выходов. Включите «Показывать микрофон на быстрой панели», чтобы в той же строке выбрать микрофон для приложения. На схеме перетащите сплошную линию, чтобы сменить основной выход. Кнопка «+» добавляет выход с отдельной регулировкой громкости и отключением звука.
- **Регулируйте громкость приложений.** По индикаторам на быстрой панели видно, какое приложение сейчас звучит. Громкость можно изменить ползунком, а для текущего приложения — колёсиком мыши над значком SonicRoute. Горячая клавиша позволяет выключить или включить сразу все микрофоны.
- **Настройте автоматизацию.** Выберите из 6 триггеров и 39 действий те, которые нужны для вашего правила. Например, при запуске игры можно сменить устройство вывода и отрегулировать громкость. Сохранённые правила можно запускать из командной строки с помощью `sr`.
- **Подключайте Android и принимайте AirPlay в редакции Full.** Подключите телефон и ПК к одной локальной сети, выберите приложение SonicRoute для Android и сверьте восьмизначный номер на обоих устройствах. Затем можно передавать звук в обе стороны и смотреть на ПК изображение с телефона. Для управления приложением на независимом виртуальном экране, передачи файлов и синхронизации текстового буфера обмена подключитесь через ADB. Full принимает звук и дублирование экрана с устройств Apple через AirPlay.

| 🎵 **Музыка или видео во время игры** | Направьте музыку на колонки, а игру — в гарнитуру. Прокруткой над значком SonicRoute можно менять громкость выбранного приложения, а с зажатой клавишей Alt — его устройство вывода. |
| ⚡ **Переход на гарнитуру при запуске игры** | Создайте правило, которое при запуске игры переключит звук на гарнитуру, установит громкость на 40 % и откроет голосовой чат. Второе правило может вернуть вывод на колонки при выходе из игры. |
| 🎙️ **Нужно отойти от компьютера или поговорить без микрофона** | По умолчанию Ctrl+Shift+N отключает и снова включает звук всех микрофонов. Включите постоянный экранный индикатор, чтобы видеть, когда звук отключён. |
| 📹 **Трансляция через OBS или запись видеоурока** | Направьте звук нужных приложений на отдельное физическое или виртуальное устройство вывода и выберите его в программе записи. Чат и уведомления оставьте на другом устройстве. |
| 📱 **Звук и приложения телефона на компьютере** | Подключите приложение SonicRoute для Android к Full, чтобы слушать телефон в наушниках ПК или видеть его экран. Если хотите управлять Android-игрой с ПК, подключитесь через ADB и откройте игру на независимом виртуальном экране. Геймпад управляет игрой, пока активно её окно. |

### ⚡ Запуск правил из командной строки

Команда `sr` передаёт имя или идентификатор правила запущенной программе SonicRoute через именованный канал. Сначала запустите SonicRoute, чтобы команда стала доступна, затем закройте и снова откройте терминал. После этого `sr` можно вызывать из скриптов, AutoHotkey и Stream Deck. Если SonicRoute закрыта, команда вернёт ошибку. Подробнее см. в разделе «[Частые вопросы](https://github.com/kunkunkunQoQ/SonicRoute/wiki/06-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98)».

```powershell
# Запустить правило автоматизации (SonicRoute уже должна работать)
sr "Имя или идентификатор правила"
```

## ❓ Частые вопросы

**Что происходит с выбранными устройствами и громкостью приложений после выхода из SonicRoute?**

Windows сохраняет основное устройство воспроизведения и устройство записи для каждого приложения, а также громкость действующих аудиосеансов. Оставьте SonicRoute запущенной для одновременного воспроизведения через несколько выходов, работы горячих клавиш, управления из области уведомлений, автоматизации, передачи звука между телефоном и ПК, трансляции экрана и синхронизации буфера обмена.

**Какая среда выполнения нужна для моей редакции?**

В EXE-файлах Full и Lite есть встроенная среда .NET 10 Native AOT. Выберите файл нужной архитектуры. Версия из Microsoft Store устанавливается и обновляется через магазин.

**Как SonicRoute в фоновом режиме влияет на нагрузку процессора и заряд батареи?**

Программа получает уведомления Windows и дополнительно проверяет состояние при необходимости. Нагрузка на процессор и расход заряда зависят от системы и используемых функций.

**Как настроить задержку звука при передаче с Android на ПК?**

В Full откройте настройки телефона, подключённого через ADB. По умолчанию выбран режим «Сбалансированный». Чтобы сократить задержку, попробуйте «Сверхнизкая задержка». Если звук прерывается, попробуйте «Стабильный». Для передачи без сжатия выберите Raw PCM в списке декодеров. Настройки вступят в силу при следующей передаче звука с этого телефона.
