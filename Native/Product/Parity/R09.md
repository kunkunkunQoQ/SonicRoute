# R-09 旧 Native AOT 产品结构与输入验证

WPF 基准为 `3d9f9e1083b228f666e30d97e3c8edfce5e6654a`。本轮从 `a9b0220` 开始，本地恢复标签为 `native-legacy-pre-r09-20261126`。滚轮检查点为 `1f49b8b`，产品源码检查点为 `ed35ade`。交付目录与源码目录并列，目录名为 `r09-release`。

## 可达入口与视图变更

- 普通设置恢复显示设备、设备名称、默认应用、杂项、语言、软件更新和关于七个分组。实验页从已解锁且已启用的导航入口进入，保留轮询、执行记录和配置管理三组。收回了历史设置入口和重复操作。各控件冻结源码位置、显示条件、命令与配置字段见[设置、实验、主题及自动化清单](R09-Settings.md)。
- Full 的添加设备入口依次显示平台选择、Android 扫码或手动配对和直接连接，已保存连接、发现结果和 USB 授权状态依条件显示。Apple 入口嵌入原有 AirPlay 接收控件。设备详情恢复设备操作、流参数、固定应用、文件传输和剪贴板。文件目录在传输卡内展开，目录的取消与已提交的后台传输分开管理。[设备、目录及传输矩阵](R09-Devices.md)
- 快捷面板手机按钮进入伴随窗。Android 区恢复独立的媒体与进度卡、筛选框、固定应用列表及底部设备选择。清除了媒体区多出的整机接收按钮、底栏常驻管理按钮、行右击启停采集和双击启动虚拟屏。管理按钮按空列表条件显示。整机音频、应用音频、返回设备和虚拟屏沿用原操作入口。行说明使用原版应用分类，播放标记读取媒体会话，断开时保留已固定应用。刷新只请求当前设备的固定应用，隐藏或换设备后过期结果作废。见 `PhoneAudioWindowView.cs` 与 `PhoneAppPresentation.cs`。
- AirPlay 接收控件只在实际显示 Apple 区时订阅。状态头和底栏改用冻结版的状态标签，移除了额外的 TCP 端口和断开按钮。接收开关、名称、解码器、PIN、正在播放的元数据和镜像窗口操作继续复用现有接收器。独立窗口及后台业务的创建条件见[双向入口清单](R09-Reachability.md)。
- 按用户追加要求，主窗收起时保留 64 DIP 图标栏。点击标题折叠，各页图标支持直接切页、选中态及本地化提示，底部箭头可重新展开。沿用 196 DIP 展开宽度、原图标、主题和 `MainSidebarCollapsed` 配置。动画期间裁剪、命中及内容占位共用当前宽度。该调整属于用户指定的产品差异。
