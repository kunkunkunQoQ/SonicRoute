# SonicRoute 1.37 屏幕提示（OSD）清单

OSD 是显示在桌面上的独立浮层，默认位于主显示器工作区右上角。普通消息显示约 1.1 秒后淡出。主窗口和快捷面板也会在自己的窗口内显示操作结果。两类反馈可以分别验证。以下为旧 Native AOT Full / Lite 的源码核对结果，标有 Full 的入口仅出现在带手机功能的版本。

## 快捷键与托盘滚轮

| 操作 | 屏幕提示 |
| --- | --- |
| 快捷键调高或调低当前应用、系统默认输出的音量 | 显示目标和当前音量。当前应用静音键显示静音或解除静音。 |
| 快捷键将所有麦克风静音或解除静音 | 显示实际切换后的麦克风状态。 |
| 快捷键切换当前应用播放设备 | 显示最终设备或失败原因。写入较慢时先显示“正在切换”。 |
| 快捷键切换当前应用录音设备、全部应用播放或录音设备、系统默认播放或录音设备 | 显示动作结果或设备名称。全部应用的播放切换还会经过单应用输出提示路径。当前应用和全部应用的录音切换键须启用实验麦克风选项。 |
| 快捷键还原全部应用默认设备 | 显示还原成功或失败。 |
| 托盘滚轮 | 普通滚轮调当前应用音量，Shift 调系统输出音量，Alt 切当前应用播放设备，Alt+Shift 切系统默认播放设备。沿用对应动作的 OSD。范围取决于托盘滚轮设置，暂停时停止这组操作。已注册的鼠标快捷键优先匹配。 |
| 打开快捷面板的快捷键、录入绑定 | 打开或收起面板本身没有 OSD。录入状态暂停正式快捷键分派，绑定结果在快捷键页内显示。规则快捷键的提示取决于所执行的规则。 |

找不到应用会话、设备不可用或执行抛错时，相应音频快捷键可以显示错误。普通输入队列已满时可显示“正在运行”。记录上次控制的应用失败时，允许显示 OSD 的调用方也可显示保存失败。[按键与滚轮分派](../Automation/AutomationAudio.cs) · [鼠标优先级](../Shell/Mouse.cs) · [绑定条件](../Automation/ProductAutomation.cs) · [输出读回](../CurrentApp/CurrentOutput.cs) · [记录当前应用](../CurrentApp/ProductCurrentApp.cs)

## 同一项操作在不同界面中的反馈

| 入口 | 操作与结果 |
| --- | --- |
| 主窗口 → 应用详情 | 选择播放或录音设备、单选或多选播放设备、恢复跟随系统、音量、静音及快捷控制，结果在本窗口的控件和页内消息中反馈。应用列表批量恢复默认也走页内反馈。这些操作本身不弹 OSD。 |
| 经典和简洁快捷面板 → 选设备 | 顶部设备框、展开的应用设备选项、输出设备音量弹层的“设为默认”，成功和失败均在面板内反馈。顶部设备框按配置决定切换系统默认端点，或只改变面板所控制的设备。 |
| 快捷面板 → 静音 | 主输出静音、底部播放静音、全局麦克风静音按钮会显示 OSD。单个应用或输出音量弹层中单个设备的静音，成功时只更新控件。 |
| 快捷面板 → 音量及错误 | 拖动主输出、应用或单个设备的音量，或选择音量预设，成功时直接更新数值。音量写入失败、单应用或单设备静音失败等会显示音频错误 OSD。保存面板高度、显示伴随面板等配置失败也可显示保存错误。 |
| 托盘右键 → 当前应用 / 系统默认播放 / 全部麦克风 | 当前应用静音、音量预设、播放设备，以及切换系统默认播放、切换全体麦克风静音，均有操作结果 OSD。若点击时应用已退出或音频操作失败，会显示相应错误。仅展开菜单时，读取失败写在菜单项上。 |
| 托盘右键 → 常用规则 / 暂停托盘滚轮 | 点击常用规则会显示规则名和执行结果，包括失败、部分成功或无法找到规则。暂停或恢复托盘滚轮成功时只更新状态，重新配置或保存失败才弹 OSD。打开主窗口、快捷面板、更新页面、退出本身没有通用 OSD。 |

允许显示的应用输出切换会延迟约 45 毫秒显示处理中提示。若已经显示，成功时保留该提示至约 500 毫秒后再显示结果，失败可直接替换。快速连续操作只让最新请求发布结果，窗口内选设备可以结束此前尚未完成的切换提示。正在生效的麦克风常驻提示有单独的生命周期。[应用页](../Views/AppsPageView.cs) · [快捷面板](../Views/QuickPanelWindow.cs) · [输出音量弹层](../Views/OutputVolumesPopupWindow.cs) · [托盘菜单](../Views/TrayMenuController.cs) · [OSD 分派](../Views/HostViews.cs)

## 自动化、外部命令和设备状态

| 来源 | 触发条件 |
| --- | --- |
| 自动化步骤“显示 OSD” | 执行到该步骤时显示配置的标题和副标题，空标题使用本地化的“自动化”。规则可由手动运行、快捷键、程序启动或退出、前台应用切换、定时、SonicRoute 启动或外部命令触发。 |
| 规则中的音频操作 | 设置或切换全局麦克风静音会显示状态。为指定应用设置播放设备，经应用输出链路显示切换结果。其他音量、静音、录音路由、设置系统默认设备或重置路由等步骤没有统一的步骤 OSD，实际麦克风状态变化仍可能触发独立监听。 |
| 自动化页手动运行 | 本页显示规则执行结果并刷新历史。托盘“常用规则”另有结果 OSD，两种入口都可能通过规则步骤产生 OSD。显示或隐藏快捷面板步骤本身只操作面板。 |
| 外部控制命令 | 常驻宿主的 `osd` 请求显示预览。`cycle-output`、`route … render …`、`outputs-set` 通过应用输出链路显示结果。查询和音量队列命令没有通用回执 OSD。外部执行规则遵循步骤行为，仅为无常驻实例的规则命令创建的临时宿主未挂接 OSD 窗口。 |
| 麦克风状态监听 | 常驻宿主监听录音端点。监控范围内的状态由静音变为未静音或反向变化时会显示短时 OSD，Windows、硬件和其他程序造成的变化也可能触发。普通播放音量或系统播放设备外部变化只刷新相应 UI，没有同类通用监听 OSD。 |
| 麦克风常驻 | 主题页可以分别选择“全部录音设备静音”和“默认录音设备静音”。任一已选择的条件成立即可显示常驻提示。两个常驻选项都关闭时，短时提醒仍按全体麦克风及配置的默认输入监控范围工作。 |

**已知显示边界。** 普通短时 OSD 覆盖常驻提示后，当前恢复代码只复核“所有录音端点均静音”。仅默认麦克风静音且其他录音设备开启时，短时提示结束后可能收起原常驻提示。[监听判定](../Automation/ProductMicMonitor.cs) · [浮层恢复](../Views/HostViews.cs) · [共享规则执行](../../../SonicRoute/AutoRuleService.cs) · [规则入口与触发器](../../../SonicRoute.Core/Models/AutoRule.cs) · [宿主命令](../HostCommands.cs) · [常驻及临时宿主](../ApplicationHost.cs)

## 主题、位置调整和手机功能

| 操作 | 反馈位置 |
| --- | --- |
| 主题 → OSD 宽度或字体倍率 | 鼠标拖动结束或键盘改动，值发生变化并成功保存后显示预览。重置 OSD 成功后也会预览，并在主题页显示重置结果。淡入淡出时间、音量进度条开关改变后，后续提示使用新设置。 |
| 主题 → 调整 OSD 位置 | 显示可拖动的 OSD 本体。松开保存，右键或 Esc 取消。位置保存失败使用原生错误对话框。 |
| 主题 → 调整快捷面板位置 | 进入时弹出拖动提示，松开并保存后显示位置已保存的 OSD。重置面板位置的反馈在主题页内。 |
| Full → 手机面板或跨设备拖放 | Android 应用拖回手机、开始手机音频或打开虚拟屏，操作出错时会显示带手机窗口标题的 OSD。把 Windows 应用拖到手机输出、手机面板刷新或重连、媒体控制等常规反馈在伴随窗口中。快捷面板断开外部音源失败可弹通用音频错误 OSD。 |
| Full → AirPlay 接收设置 | 接收端名称、视频解码或连接码要求保存失败时显示保存错误 OSD。接收和镜像状态在对应面板、镜像窗口内显示。 |

主窗口的页内通知由当前窗口绘制，约 3.2 秒后收起。设备错误文字、下拉框悬停提示、录入冲突警告、更新菜单项、虚拟屏恢复状态窗和原生确认对话框均有各自的显示入口。Windows 自身的音量浮层也由系统控制。[主窗口提示](../Views/MainWindowShell.cs) · [主题页](../Views/ThemePageView.cs) · [可拖动 OSD](../Views/OsdWindow.cs) · [跨设备拖放](../Views/CrossDeviceDragHost.cs) · [手机面板](../Views/PhoneAudioWindowView.cs) · [AirPlay 设置](../Views/AirPlayReceiverViewControl.cs)
