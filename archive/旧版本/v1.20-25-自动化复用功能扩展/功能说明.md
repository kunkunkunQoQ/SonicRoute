# 自动化复用功能扩展（阶段 25）

日期：2026-10-01；版本 1.20；实施用户选择的 1、2、3、4、5、8 项。

## 使用入口

| 功能 | 使用方式 | 行为 |
|---|---|---|
| 明确静音状态 | 操作下拉选择“设置系统/应用静音状态”，选择静音或取消静音；应用动作另选目标应用 | 每次写入指定状态，重复执行保持目标状态 |
| 相对音量 | 操作下拉选择“增减系统/应用音量”，滑块选择 -100～100 | +5 为增加五个百分点，-5 为减少五个百分点；结果裁剪到 0～100 |
| 全局麦克风 | 选择“设置全局麦克风静音状态”或“切换全局麦克风静音” | 复用所有录音设备静音接口，按实际状态更新现有麦克风 OSD/常驻 |
| 立即执行 | 已保存规则行点击“立即执行” | 按步骤顺序和延时真实运行，反馈逐步统计；自动禁用的规则也可手动运行 |
| 复制规则 | 规则行点击“复制” | 新名称/Id，独立步骤、启动项及星期；默认禁用，快捷键/执行记录清空 |
| 复制步骤 | 编辑步骤头部点击“复制” | 新步骤插在原步骤后，复制参数、延时、启动项及打开方式 |
| 启动触发 | 触发方式选择“SonicRoute 启动时” | 当前程序下一次启动，在初始化和音频预热完成后执行一次启用规则 |

复制出的规则可以编辑、绑定快捷键或设置触发；保存沿用原行为启用规则，亦可用规则行启用/禁用按钮控制自动触发。

规则名称和按钮区采用两行，按钮容器使用 WrapPanel；新按钮及参数复用原 GhostButton、SelCombo、音量滑块、应用下拉与颜色分类。窗口关闭后手动结果不再更新界面。

## 实现与兼容

- AutoRuleTrigger 保留 0～4，新 Startup=5；旧规则编号不变。
- AutoRuleAction 保留 0～10，新 11～16 依次为 SetSystemMute、SetAppMute、AdjustSystemVolume、AdjustAppVolume、SetGlobalMicMute、ToggleGlobalMicMute。
- 新步骤字段 Muted 默认 true、VolumeDelta 默认 +5；范围 -100～100，并同步首步骤兼容镜像。Clone、ToPersisted、CloneSteps、SetSteps 统一处理。
- CopyAsNew 生成新 Id，深复制步骤/启动项/星期，Enabled=false、Hotkey/LastRunKey 留空；复制规则名称按当前语言加副本后缀并检查重名。
- 动作/触发下拉通过 ComboBoxItem.Tag 取 enum，动作标签在下拉与摘要共用；摘要包含明确状态和音量变化。
- 本地 config-editor 数据模型、导入/导出、首步骤镜像、滑块/静音选择器、启动触发与复制默认禁用均同步；网页仍是本地配置编辑器，未增加系统音频执行接口。

## 执行与性能边界

同一进程内同一规则正在执行时，重复请求忽略并报告正在运行；不同规则可并发执行。启动触发每个进程一次，Lite/Legacy 共享规则但独立启动各执行一次。App 在 UI 进入交互前捕获当时启用的 Startup 规则 Id，预热完成后回查是否仍存在、启用且仍为 Startup；启动期间新建或新启用的规则等下次启动。

运行前复制步骤快照；编辑/复制规则不会改动正在执行的步骤。失败后继续后续步骤，建议中的“失败时中止”尚未实施。指定应用录音会话静音也尚未添加。

新增动作使用现有 Core 音频接口，应用 PID 解析与音频写入在后台任务中完成。Startup 等待原后台预热，没有新增常驻采样、计时器或监听器；原应用触发 1s 监听、定时单发调度及快速面板电平 33ms/2s 保持。

长延时的手动报告持有窗口弱引用，避免任务延时持有已关闭的管理界面。退出取消等待并停止发起后续步骤；已经发起的音频/程序操作按其原流程完成。

## 静音结果修正

阶段 24 发现的状态 bool 问题已修复：

- 系统切换：读取当前状态后调用 SetMute，返回实际写入成功。
- 应用切换：ToggleMuteChecked.Applied。
- 明确静音：使用对应 SetMute 的成功返回。
- 相对音量：AdjustVolumePercent.Applied。
- 麦克风：写入成功与读回静音状态分别保存，显示结果复用原 OSD 路径。

ExecuteAsync 对既有调用者仍返回“至少一步成功”；手动入口使用 ExecutionResult 的成功/失败数区分全部成功、部分失败、全部失败。程序/PowerShell 步骤的成功沿用原“已提交启动”语义，不等待脚本内部执行完毕。
