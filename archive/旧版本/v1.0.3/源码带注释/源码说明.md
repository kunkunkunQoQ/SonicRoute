## 核心机制（重点注释）

### 1. 按应用切换输出设备（EarTrumpet Per-App Routing）
- 不修改 Windows 系统默认设备
- 关键接口：`IAudioPolicyConfigFactory` → `SetPersistedDefaultAudioEndpoint`
- 设备 ID 需包装为完整接口路径：`GenerateDeviceId` / `UnpackDeviceId`
- 见 `SonicRoute.Core/AudioService.cs` 的 `ApplyEndpoint`

### 2. 单独应用音量
- 按 PID 聚合全部输出会话，逐个 `ISimpleAudioVolume.SetMasterVolume()`
- 绝不触碰系统主音量
- 见 `SonicRoute.Core/SessionVolumeService.cs`

### 3. 当前应用自动检测
- `CurrentAppService`：每 1.5s 查一次前台 PID，变化时才做音频会话匹配
- 三种模式：最近使用(recent) / 上次操作(last) / 指定(fixed)

### 4. 全局快捷键
- 动作 → 组合键（如 Ctrl+Alt+Space），注册失败自动回退默认并提示

### 5. 应用自定义名称（v1.0.3）
- config.json `AppNames`：进程名 → 显示名
- 「应用」页选中应用即可重命名，留空保存 = 恢复默认
- `AppDisplayName.Get(app)` 统一解析：有自定义名用自定义名，否则用默认 Label
- 通知/OSD（App.xaml.cs）、面板、概览、应用列表全部走它，改一处全局生效

### 6. 设备自定义名称
- config.json `DeviceNames`：短 ID → 显示名；通知/OSD/列表统一显示
