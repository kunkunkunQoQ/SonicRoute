# SonicRoute v1.0.6 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物）。相对 v1.0.5r4 的改动点如下。

## v1.0.6 改动点

### 1. 新增：禁用自动切换当前应用（核心新功能）
- **ConfigService.cs**（`SonicRoute.Core`，`AppConfig`）：新增 `List<string> DisabledAutoSwitchApps`（进程名列表）持久化到 config.json
- **CurrentAppService.cs**：
  - `MatchForeground` 增加禁用过滤——被"禁用自动切换"的应用不参与前台匹配（前台监听、直接前台全部跳过）
  - `Resolve` 所有自动分支（last/fixed 显式指定、直接前台、最近使用、上次操作、兜底）都跳过已禁用应用；全部被禁用时回退列表第一个
- **AppItem.cs**：新增 `IsAutoSwitchDisabled`（INPC）+ `DotBrush`（主题色 RGB 反色，未禁用为透明）+ `RefreshAutoSwitchState()`
- **ThemeService.cs**：新增 `GetInvertedAccentBrush()`——取当前 `Theme.Accent` 的 RGB 反色（255-R/G/B）
- **MainWindow.xaml**：
  - 应用列表 `AppItemTemplate`：图标包进 Grid，右上角加 6px Ellipse 状态点（Fill=DotBrush，Visibility=IsAutoSwitchDisabled）
  - 应用详情页：静音按钮旁新增「禁用自动切换」按钮（GhostButton，与静音同款）
  - Window.Resources 加 `BooleanToVisibilityConverter`（x:Key=BoolToVis）
- **MainWindow.xaml.cs**：`AppsDisableAutoButton_Click`（切换状态+保存）、`UpdateAppsDisableAutoButton`（按钮文字）、`LoadAppsAsync` 初始化状态点、`Theme_Changed` 切换主题/强调色后刷新状态点反色
- **L10n.cs**：新增 `Apps.DisableAuto` / `Apps.DisableAutoOn`（8 语言）

### 2. 修复：快捷键与任务栏滚轮应用解析一致
- **App.xaml.cs**（`ExecuteHotkeyAsync`）：不再优先用共享 `CurrentAppService.Current`（可能滞后/过期），改为与托盘滚轮完全一致的 `CurrentAppService.Resolve(apps, cfg)` 路径，快捷键与"任务栏滚轮调音量"永远解析出同一个应用

### 3. 修复：任务栏 OSD 应用名显示自定义名称
- **TrayWheelService.cs**：滚轮 OSD 应用名由 `GetProcessNameSafe(pid)`（原始进程名）改为 `AppDisplayName.Get(进程名, 进程名兜底)`——自定义名优先，无自定义显示进程名，两者都拿不到才显示"应用"

### 4. 修复：粉色强调色下方 RGB 预览色块显示粉色
- **MainWindow.xaml.cs**（`SyncRgbUi`）："purple" 色值由紫色 `#8B5CF6` 改为粉色 `#EC4899`，与 `ThemeService` 一致（此前选粉色时下方 RGB 预览/滑块/十六进制仍显示紫色）

### 5. 版本号统一 v1.06
- MainWindow.xaml / App.xaml.cs（托盘）/ QuickPanelWindow.xaml / L10n.cs（8 语言 About）
