音跃 SonicRoute v1.12 改动说明
================================
## v1.12（测试版 v1.12a，未上传 GitHub）

### 🆕 新增功能

- **全新简洁快速面板（默认）+ 设置切换新旧**：新增「简洁面板（Compact panel）」—— Win11 音量飞出式布局（当前应用/系统音频设备下拉 + 大音量滑块行 + 全部有音频应用逐行列表 + 全局输出静音 / 全局麦克风静音 + 完整界面按钮），默认启用；原面板更名「经典面板（Classic panel）」可在设置→启动选项→「快速面板样式」下拉切换；新旧面板共用 `IQuickPanel` 接口（快捷键/托盘/音量/静音统一调用），简洁面板继承经典面板全部优化（滚轮调音量、失焦自动关闭、Esc 关闭、保留设备筛选、自定义设备名、OSD 通知）；新增 4 个多语言 key × 9 语言（Qp.FullUi / St.QuickPanelStyle / St.PanelClassic / St.PanelModern）
- **简洁面板应用列表**：全部有音频的应用逐行列出，每行 = 应用图标（点击静音，静音后音量条/百分比变强调色 RGB 反色 + 图标右上角反色圆点）+ 独立音量滑块（90ms 防抖写回，支持鼠标滚轮 ±4% 调节）+ 百分比 + ▾（折叠展开设置该应用输出/输入设备：保留设备筛选 + 自定义设备名 + 当前设备高亮）；同时打开两个应用折叠时自动关闭上一个（折叠互斥）；修复行滑块 Thumb 无法拖拽问题
- **面板反馈改 OSD**：简洁面板所有操作反馈（静音 / 全局静音 / 全局麦克风静音 / 行静音 / 音量调整 / 设备切换 / 加载失败）从底部状态文本改为右上角 OSD 通知；删除状态文本 TextBlock，修复反馈文本把「全局输出静音」按钮顶掉的问题
- **按钮状态强调色**：快速面板（经典 + 简洁）静音 / 全局输出静音 / 全局麦克风静音、完整 UI 应用页静音 / 禁用自动切换 / 禁用在快速面板显示按钮——启用/禁用状态文字变强调色（Theme.Accent），文本固定为动作名、不切换文案（不再显示「取消静音 / 已禁用自动切换 / 不在快速面板显示」）；删除按钮旁状态文本反馈；「在快速面板显示」文案改为「禁用在快速面板显示」（9 语言）
- **静音快捷键 = 系统设备**：静音快捷键语义改为控制系统设备（不改系统默认设备），与面板/概览顶部显示一致
- **完整界面「在快速面板显示」开关**：应用列表可单独关闭某应用在快速面板显示（HiddenPanelApps）；禁用自动切换的应用图标右上角显示强调色反色小圆点
- **OSD 自由调整简化 + 主题页副本**：实验设置 OSD 区块简化为「調整位置（拖拽定位，松手保存）+ 一键还原位置」两个按钮（删除下拉 9 宫格 / X-Y 坐标输入 / 偏移微调 / 小字说明），同功能副本放主题页最下方；后续实验设置的 OSD 块删除，仅保留主题页
- **繁体中文（zh-tw）**：`L10n.cs` 新增 `BuildZhTw` 表 + `SupportedLanguages` 注册「繁體中文」+ `BuildTable` 分支；系统语言为 zh-HK / zh-TW / zh-MO / zh-Hant 时默认用繁体；按港澳台综合本地化（微软繁体 Windows 译法基准），不区分港台版本；补齐 v1.12 曾遗漏的 9 个多语言键 × 9 语言；语言总数 8 → 9
- **翻译规范**：新增 `翻译规范.md`（术语表、繁简检查清单、脚本编码铁律、交付核对清单）；全语言漏译核验（繁体 43 处简体残留修正）
- **内存优化落地**：删除实验设置「关闭 UI 释放内存 / 释放快速面板 UI 内存」入口；执行内存优化方案 2/3/4/6（含启动后约 15s 提前 GC 回收等），后台与打开面板后占用显著降低
- **开机自启相关**：设置页新增「清理自启项」按钮（绿色版删 Run 键 / 商店版禁用 StartupTask；商店版不显示）；商店版开机自启独立存储（AutoStartStore）与正常版互不影响；启动自检修复（自启 Run 键路径与当前 exe 不一致自动修复）
- **UI 收纳**：「清理自启项」按钮移入「开机自启」下的「显示更多选项」折叠区；「在快捷面板显示麦克风」作为「麦克风选项」子选项收进其「显示更多选项」折叠区
- **构建**：Lite 版约 25.8MB；发布方案一自动化验证通过
