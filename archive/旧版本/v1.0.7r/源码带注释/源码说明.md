## v1.0.7r 改动点

### 1. 实验设置「关闭 UI 释放内存」GC 增强
- **原因**：原实现是窗口关闭后延迟 300ms 触发**一次** `GC.Collect()`。但窗口关闭瞬间可能有挂起的异步续体（切设备 / 调音量 / 刷新应用等，闭包会捕获窗口对象），单次过早 GC 会错过回收，导致「关闭 UI 释放内存」偶尔不生效
- **改动**：改为**立即回收 + 延迟多次重试（1s / 3s / 5s）**，每次 `GC.Collect()` 两轮含终结器队列（`GC.WaitForPendingFinalizers()`），确保异步续体跑完后窗口与视觉树被真正回收
- 新增 `App.GcNow()` 辅助方法（try/catch 包裹）
- 涉及文件：`SonicRoute\App.xaml.cs`（`GcNow()` + `ShowMainWindow` 的 `Closed` 处理）
