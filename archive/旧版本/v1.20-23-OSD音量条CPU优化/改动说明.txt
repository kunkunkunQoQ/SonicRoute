音跃 SonicRoute v1.20 OSD 音量条 CPU 优化
日期：2026-10-01，基线阶段 22，本阶段 23 本地未上传、未发布。

用户授权实施连续按键/滚轮时音量条的性能方案。本阶段只修改共享 OsdService.cs，Lite x64 和 Legacy 链接同一源码；版本仍为 1.20.0.0，音量数字保留左侧即时显示。
1. 缓存条的目标比例、目标身份和活动状态，同目标不重启动画；无活动时钟不调用 BeginAnimation(null)。待请求先 B 后回到活动目标 A 时取消 B、保留 A 的动画。
2. 只保留绘制前最新条目标；按需注册 Rendering，活动动画两次重启至少相隔 33ms，请求处理/取消即解除。完成回调只清自身时钟，不丢弃后续请求。没有新增计时器、空闲持续刷新或音频查询。
3. 仅音量条 90ms 过渡的 DesiredFrameRate=30；实际帧率不保证，数字和原淡入淡出不降帧。
4. 复用冻结 QuadraticEase；真实轨道宽度乘 DPI 后变化不足一个物理像素时直接应用准确目标，不创建动画，不量化数字。
5. 首次显示/切目标/系统动画关闭/Tier 0/开关通知即时应用；通用提示、隐藏、关闭开关和退出清待请求/时钟/身份；保留原主题色、数字布局、窗口定位和麦克风逻辑。

Lite x64 publish / Legacy Release build 均 0 错误。Lite 日志输出 8 次既有警告（WPF 临时/正式工程重复计入），Legacy 42 个既有可空性警告；OsdService 无新增警告。
