二、v1.18 正式版变更（相对 v1.17 正式版）
   1. 简洁面板固定高度
      - 窗口高度恒定可调（主题 → 快速面板，350~800，默认 350）
      - 展开 / 收起 / 切换应用均不改变窗口高度，底部锚定不晃动
      - 输出静音 / 麦克风 / 完整界面固定在面板最底部，应用区中间滚动
      - 呼出时 RootBorder 轻量上移淡入动画
   2. 自动化增强
      - 新增触发方式：应用退出触发、定时触发（仅一次 / 每天 / 每周；
        错过执行时间自动跳过不补执行；仅一次执行后自动禁用、可手动重新启用）
      - 规则支持禁用 / 启用（状态点），状态持久化
      - 自动化应用列表显示图标，8 秒低频自动刷新
   3. 多语言
      - 九语言审查通过，繁体中文用语统一为「儲存」
   4. 文档
      - README 更新版本号 / 下载表 / 更新日志 / 预览动图
