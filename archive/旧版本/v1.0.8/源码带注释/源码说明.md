# SonicRoute v1.0.8 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物，commit `285340f`）。相对 v1.0.7r2 的改动点如下。

## v1.0.8 改动点

### 1. 1080p 高清图标
- 新增 `背景\1080.png`（1080x1080 高清源图），从此前的 256x256 `SonicRoute.png` 升级
- 从 1080p 源图高质量缩放重新生成全部图标资产：
  - MSIX：Square44x44 / Square150x150 / Square310x310 / Wide310x150（居中裁剪 2:1）/ StoreLogo 50x50
  - 项目：`SonicRoute\SonicRoute.png`（窗口+托盘，256x256）、根目录 `图标.png`（256x256）
- 所有图标验证透明背景（A=0）

### 2. MSIX 任务栏图标透明修复
- **问题**：MSIX 基础 `Square44x44Logo.png` 会被系统自动套背景色块（即使 `BackgroundColor="transparent"`），任务栏显示不透明
- **修复**：新增 `Square44x44Logo.targetsize-16/24/32/48/256.png` 五种尺寸图标（从 1080p 源图缩放），`targetsize-*` 版本不会被系统加背景，原样透明显示
- 涉及：`dist\msix\pkg\Assets\`、`dist\msix\pkg_lite\Assets\`

### 3. MSIX 开机自启修复
- **问题**：原代码写注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，MSIX 沙箱会把注册表写入重定向到包内私有位置，系统开机读不到，导致开机自启不生效
- **修复**：
  - 清单（`AppxManifest.xml`）新增 `windows.startupTask` 扩展：
    ```xml
    <desktop:Extension Category="windows.startupTask" Executable="SonicRoute.exe" EntryPoint="Windows.FullTrustApplication">
      <desktop:StartupTask TaskId="SonicRouteStartup" Enabled="false" DisplayName="SonicRoute" />
    </desktop:Extension>
    ```
  - 代码（`MainWindow.xaml.cs`）新增 `IsPackaged()` 检测：MSIX 环境用 `Windows.ApplicationModel.StartupTask.GetAsync()` + `RequestEnableAsync()` / `Disable()` 控制；非 MSIX（绿色版）保留注册表方式
  - `SettingsAutoStart_Changed` 改为 `async void`，按环境分支处理

### 4. TFM 升级（支持 WinRT API）
- `SonicRoute.csproj`：`TargetFramework` 从 `net8.0-windows` → `net8.0-windows10.0.19041.0`
- 原因：调用 `Windows.ApplicationModel.StartupTask`（WinRT API）需要 Windows 10 1903+ TFM
- 影响：Lite 版体积从 ~1.2MB 增至 ~25MB（WinRT 互操作库打入 single-file），仍远小于正常版；绿色版正常运行不受影响

### 5. 版本号
- `v1.0.7r2` → `v1.0.8`（App.xaml.cs 托盘 / MainWindow 标题与概览 / QuickPanel / L10n 8 语言 `App.About` / csproj `<Version>`）
- MSIX 清单 Version：`1.0.7.0` → `1.0.8.0`

### 6. 新增 WpfUiSkeleton 模板项目
- `WpfUiSkeleton\`：从 SonicRoute 抽离的可复用 WPF UI 骨架（无边框圆角窗口 + 主题切换 + 强调色 + 透明度 + 多语言），零第三方依赖，可直接复制到新项目使用
