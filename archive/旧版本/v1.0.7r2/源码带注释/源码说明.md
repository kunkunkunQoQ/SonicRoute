# SonicRoute v1.0.7r2 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物，commit `7aeb7e3`）。相对 v1.0.7r 的改动点如下。

## v1.0.7r2 改动点

### 1. 实验设置新增子选项「释放快速面板 UI 内存」
- 挂在「关闭 UI 释放内存」下方（主开关开启时显示，缩进子选项），独立持久化 `FreePanelUIMemory`，实时生效
- 开启后，每次关闭快速面板（托盘 / 快捷键触发）触发**立即 + 1/3/5s 多次强制回收**（复用 `GcNow()`），回收面板 UI 占用的内存；与主开关互相独立（只开子选项也生效）
- 涉及文件：
  - `SonicRoute.Core\ConfigService.cs`：新增 `FreePanelUIMemory` 字段
  - `SonicRoute\App.xaml.cs`：`ToggleQuickPanel` 关闭分支——面板关闭后若开启子选项则启动延迟多次 GC
  - `SonicRoute\MainWindow.xaml/.cs`：实验设置页子选项 CheckBox + 可见性联动（主开关开启才显示）+ 切换事件
  - `SonicRoute\L10n.cs`：新增 `Exp.FreePanelMem` / `Exp.FreePanelMemHint`（8 语言）
