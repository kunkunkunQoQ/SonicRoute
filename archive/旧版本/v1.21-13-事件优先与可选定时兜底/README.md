# v1.21 阶段49：事件优先与可选定时兜底

2026-10-09 的发布前历史快照，包含新透明耳机图标及三个界面英文顶部名称。当前版本和下载以仓库首页及 v1.21 Release 为准。

- `源码快照/`：97份当时生产文件、5份公开打包文件，没有诊断注入。历史发布配置保留创建时状态；当前 Lite 配置以仓库根目录为准。
- `测试/`：自包含的功能复现驱动、14份明确隔离覆写、两个无声/进程辅助项目。覆写仅供诊断，禁止回写生产。
- `检查证据/`：Lite/Legacy各144项功能断言0失败；另各有34项实际主面板目标检查。实际普通前台切换12/12准确、密集切换最终目标正确。
- 稳定后台本机隔离测量总工作集11.24–16.61MiB、私有提交均值114.91MiB。工作集整理不是私有提交释放；整体CPU下降尚未得到证明，数字不保证在所有设备重现。
- 实验兜底默认关闭、立即生效；健康时仅事件，有限无会话重试，可见故障临时恢复。设备通知保留；静默丢通知不保证检测到，其它自动化/电平/规则目录计时器仍保留。主程序不主动强制GC。
- `SHA256SUMS.json`：除清单自身外全部文件的SHA256，复制后核对。无用户配置、私有规范、签名材料或运行二进制。

Windows、PowerShell 7、.NET SDK及.NET Framework 4.8编译条件下，从此目录复现：

```powershell
& ./测试/Reproduce-Checks.ps1
```

默认不切换实际前台；添加`-IncludeForeground`才会切换自己的无声测试窗口。检查配置/规则/日志/命令通道隔离，禁止真实音频写入。某些弱引用生命周期断言使用诊断GC，生产和常驻内存测量不使用该诊断GC。

详细当前使用方式及发布说明见仓库`docs/release-v1.21.md`和Wiki。源码快照不包含后续发布文档与发布配置调整。
