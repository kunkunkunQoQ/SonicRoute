# 1.21 工作区：主题与设置界面

主题页使用模式与配色按钮、自定义颜色及预览、背景透明度、OSD 外观、快速面板设置等卡片。工作区版本为 1.21，正式下载仍为 1.20。

## 模式与配色

跟随系统、浅色、深色是一组；蓝色、绿色、粉色、自定义为另一组。模式和强调色可以独立组合，选中项有边框及勾选提示，空间不足时自动换行。

自定义色支持：

- 输入六位十六进制颜色，可以带 `#`；按 Enter 或离开输入框时应用，Esc 恢复当前值。无效输入（包括数字中夹杂空格）恢复原值并提示。只聚焦后离开不会将预设色改成自定义色。
- “选择颜色”菜单打开系统颜色选择器；取消不修改颜色。
- “高级颜色设置”展开原有 R/G/B 滑块，选中“自定义”后可用滑块调整强调色，沿用现有预览合并、延迟保存和展开动画。

右侧界面预览为静态 WPF 矢量示意，直接引用共享主题画刷。它不创建真实窗口副本、不截图刷新，也不增加后台计时器。主题颜色变化时通过动态资源更新。Lite 与 Legacy 共用同一份主题资源；Legacy 工程显式链接 `ThemeControls.xaml`，确保运行时可以载入。

## 透明度与 OSD

背景透明度独立为一张卡片，范围及保存逻辑沿用旧设置。百分比显示在滑块右侧；建议至少 50% 的提示仅作建议，不限制较低值。

OSD 卡片标题右侧提供调整位置和还原位置，音量进度条及静音常驻使用共用开关样式；宽度、字号、淡入淡出和静音监听子选项仍可展开。快速面板位置、简洁面板高度和实时电平开关也保留。

本轮同时把自动化步骤的延时输入改为与启动模式、启动列表相同的左对齐列，输入文字也左对齐。延时范围、字段写回和步骤执行方式不变。

## 设置页

设置页沿用主题页的卡片、标题、提示文字和矢量图标。保留设备使用可勾选的设备卡片；设备名称行左侧显示原始名称与设备信息，右侧编辑自定义名称，清除按钮恢复默认名称。输出、输入及系统默认设备共用构造方法，输入设备仍受麦克风选项控制。

默认应用改为最近使用、上次操作、指定应用三张选项卡，继续共用原有选项和指定应用下拉。启动行为与其他选项集中在杂项卡片，整行可以切换右侧开关；原有的设备区块折叠、全选、麦克风子选项、语言管理和作者入口保留。设置项、默认值及保存逻辑不变；参考图中的记住窗口位置没有新增为功能。

清理范围包括确认无生产代码引用的 `SystemDevItemTemplate`、旧设备勾选框的重复构造和旧名称编辑行。主题与设置页的七处“更多选项”使用共用文字与箭头模板，展开时沿用强调色，不再显示系统按钮底色。仍被概览、快捷面板、实验设置或自动化使用的共享样式继续保留。

## 验证范围

Lite x64、Legacy x64 和 ARM64 均通过编译；Lite 与 Legacy 已进行隔离界面验收，ARM64 未经真机验证。资源对比采用 1.20 与当前源码的相同隔离保护和编译参数，比较主题页、设置页、50 条禁用规则列表静置，以及固定频率的合成 OSD 音量更新场景。

隔离测试跳过真实启动编排并重定向测试数据，因此其 CPU、私有内存与工作集结果只适用于测试中的 WPF 界面负载，不能作为已发布程序完整托盘或音频后台长期占用的结论。具体测试条件和结果以本轮测试报告为准。

## 手动体验

退出旧实例后，打开本轮 Lite x64 开发程序，可按以下顺序查看：

1. 在主题页切换浅色、深色及预设色，查看选中边框、图标、静态预览与文字对比。
2. 在自定义颜色框输入 `#00FFB0`，按 Enter；输入无效值后离开输入框，应恢复当前颜色并提示。展开高级颜色设置，拖动 RGB 滑块，检查预览和保存。
3. 在设置页展开保留设备，切换单个设备及全选，再恢复原选择。修改设备名称，检查其他界面的名称更新；点击清除按钮恢复原名。
4. 切换最近使用、上次操作和指定应用，只有指定应用模式启用下拉选择。点击杂项开关的文字或右侧开关，都应只切换一次。
5. 缩窄窗口，检查卡片换行及名称编辑框；进入自动化编辑器，检查启动模式和延时输入框是否左对齐。
