音跃 SonicRoute v1.0.2 改动说明
================================
归档时间：2026-08-27
源码快照：git commit d4a58bf

相对 v1.0.1（初版，核心按应用切换）的更新内容：

1. 多语言 8 种
   - 新增：中文 / English / 日本語 / 한국어 / Français / Deutsch / Español / Русский
   - 首次启动跟随系统语言，设置里下拉切换（重启生效）

2. 全局麦克风静音
   - 一键静音/取消静音系统所有录音设备（设备级，IAudioEndpointVolume），与当前应用无关
   - 面板 / 概览 / 快捷键均可操作

3. 改键优化
   - 快捷键改为内联录音（免弹窗），按下即生效
   - 修复数字键格式（D1 → 1）与注册刷新顺序

4. 通知 / OSD
   - 显示自定义设备名（与设置页"设备名称"一致）
   - 长文本自动省略，防止 OSD 位置漂移

5. 界面微调
   - 概览页移除刷新按钮
   - 完整界面左侧导航透明度统一
   - 全局麦克风静音按钮加宽（防长文本截断）

6. 发布形态
   - 首次提供"绿色免安装版（自包含）" + "轻量版（框架依赖）"两种发布形态
   - GitHub Release 同时上传 zip 与 exe
