# SonicRoute v1.0.4 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物）。项目结构与核心机制同 v1.0.3，以下仅列 v1.0.4 相对 v1.0.3 的改动点。

## v1.0.4 改动点

### 1. 应用重命名改为「输入即自动保存」
- **MainWindow.xaml**：移除「✎ 保存名称」按钮，TextBox 挂 `TextChanged="AppsRenameBox_TextChanged"`
- **MainWindow.xaml.cs**：
  - 删除 `AppsRenameSave_Click`，新增 `AppsRenameBox_TextChanged`——每次输入即写入 config 并保存
  - 新增 `_suppressRename` 标志：程序设置 TextBox 文本时不触发保存（避免 SelectionChanged 初始化时误写）
  - 新增 `_appItems` 缓存：改名后只刷新对应列表项的 Label，**不重建 ItemsSource**（避免中文输入法组合中断，这是设备改名已踩过的坑）
- **AppItem.cs**：实现 `INotifyPropertyChanged`，新增 `RefreshName()` 仅通知 Label 变化
- **L10n.cs**：`Apps.RenameHint` 8 语言更新为"输入即自动保存"语义（`Apps.RenameSave/Saved` 保留未用）

### 2. 多语言按需加载（内存优化）
- **L10n.cs 重构**：原 8 段语言字典（静态一次性全量加载）拆为 8 个独立方法：
  - `BuildZh()/BuildEn()/BuildJa()/BuildKo()/BuildFr()/BuildDe()/BuildEs()/BuildRu()`
- 新增 `BuildTable(lang)` switch 分发 + `BuildTables()` 懒加载：**只构建当前语言 + zh-CN 兜底表**
  - `Tables` 改为 `_tables ??= BuildTables()`，首次访问才构建
  - 启动流程不变：App.xaml.cs 先 `SetLanguage(config.Language)` 再创建窗口，故首次访问即用正确语言
  - 语言切换仍"重启生效"，切换只改 `CurrentLanguage`，不触发新语言构建

### 3. 主题强调色「紫色 → 粉色」
- **ThemeService.cs**：`"purple" => (0x8B,0x5C,0xF6)` 改为 `(0xEC,0x48,0x99)`（#EC4899 粉色）；预设名仍为 `purple`（配置兼容）
- **L10n.cs**：`St.AccentPurple` 8 语言同步改"粉色/Pink/ピンク/분홍/Rose/Rosa/Розовый"

### 4. 版本号 v1.0.3 → v1.0.4
- **SonicRoute.csproj**：`<Version>1.0.4</Version>`
- **L10n.cs**：`App.About` 8 处 v1.03 → v1.04

## 构建
```
dotnet build SonicRoute.sln -c Debug
# 自包含单文件（绿色免安装）
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist\publish-single
# 自包含完整目录（zip 解压即用，推荐发布形态）
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:DebugType=None -o dist\publish-dir
# 轻量版（框架依赖）
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -o dist\publish-lite
```

> 注意：单文件自解压 exe 在部分环境（如构建机安全软件实时防护）可能无法启动；完整目录 zip 版无此问题，两个形态都提供。
