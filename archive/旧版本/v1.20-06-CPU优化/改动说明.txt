音跃 SonicRoute v1.20 CPU 优化阶段备份
备份日期：2026-10-01
状态：CPU 优化后，本地开发版；主仓库基于 master 7d0374e，尚未提交上传、未发布。
上一阶段：v1.20-05-CPU优化前（86 文件）。

内容：
- 源码带注释：73 文件，含 SonicRoute、SonicRoute.Core、SonicRoute.Legacy、解决方案、图标、README 与 AI_CONTEXT；无 bin/obj。
- 可运行版本：Lite-x64 单 exe；Legacy-x64 12 个运行文件，无 pdb。
- 两版 exe 与 Legacy Core.dll 文件版本 1.20.0.0，两版 exe PE=0x8664/x64。
- Lite 使用 .NET 8 Desktop Runtime；Legacy 使用 .NET Framework 4.8，运行时依赖与之前相同。

改动：
1. 自动化监听单个指定进程名时缓存一个匹配进程的句柄，存活时只读取 HasExited；缓存实例退出后查询同名其他实例，最后一个实例消失才触发退出。多目标、旧空目标与带 .exe 的旧规则仍使用原全量快照。1 秒轮询保留，首次基线后台获取，停监听释放句柄。
2. 麦克风 2 秒轮询单飞、停止/选项变化后不采用旧结果；两类静音状态查询共用一个枚举器，保持读写语义，异常时清理部分 COM 引用。
3. idle 首次 15 秒、之后每 120 秒检查内存；首次后仅距上次回收至少 120 秒且托管堆增长至少 8MiB 或私有内存增长至少 16MiB 才回收，稳定托盘状态不再重复完整 GC。关闭最后一个 UI 后延迟 1.5 秒的单次回收保留；任务防重入与 CTS 清理完善。
4. 图标 Lazy 防同路径并发重复提取，按最近访问顺序淘汰；有 UI 上限 256、关闭全部 UI 后 32，减少下次打开的提取，空闲内存可能略增。
5. 简洁面板重复加载合并；应用/设备/语言/主题结构签名相同复用行和展开状态，只刷新音量/静音。初始读回或刷新滑块不排队写入音量，批量刷新只更新一次采样目标。
6. 电平发布量化到 0.001（最大误差 0.05%），内部平滑仍保留完整精度；渲染宽度按实际 DPI 取物理像素，相同像素不重复写 ScaleX。继续 33ms 采样、2 秒会话重扫；范围保持所有面板列出且未静音、滑块可用的应用，滚出屏幕仍采样，静音段不降采样频率。
