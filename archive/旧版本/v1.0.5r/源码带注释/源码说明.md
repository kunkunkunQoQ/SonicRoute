# SonicRoute v1.0.5r 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物）。相对 v1.0.5 的改动点如下。

## 版本命名规范（本次起生效）
- 后缀 `a` = 测试版（不上传 GitHub，不归档）
- 后缀 `r` = 修复 bug 后的正式版本（上传 GitHub、归档）
- 程序集内部版本保持纯数字（csproj `<Version>1.0.5</Version>` 不变），对外发布/界面显示用 `v1.0.5r`

## v1.0.5r 改动点

### 1. 应用图标更换（用户指定素材）
- **源文件**：`图标.png`（仓库根目录，用户提供，61x57 深蓝色简约耳机线稿、白色背景）
- **SonicRoute.png**（内嵌资源，托盘/窗口图标）：
  - 脚本处理：白底抠除（亮度 > 232 → Alpha=0）→ 保持比例放大到 256x256（HQ 插值，居中，图标区约 216x202）
  - 透明背景，`IconFactory` 仍读内嵌 `SonicRoute.png`，无需改代码
- **SonicRoute.ico**（exe 图标）：从处理后的透明 PNG 生成多尺寸 ICO（16/24/32/48/64/128/256），**每个尺寸带标准 BITMAPINFOHEADER（40 字节）文件头**——这是上轮"exe 图标缺失"的根因（缺文件头导致 ICO 结构非法），本版已修复
- 注意：白底小图放大后会偏糊，属素材分辨率限制；如需更清晰可提供更高分辨率源图

### 2. 设置页全选改为按键
- **MainWindow.xaml** 行 ~601：`SelectAllOutputButton` 样式 `GhostButton`（弱化文字按钮）→ `PrimaryButton`（强调色实心按键，圆角、白字、hover 变色），`Height=26, Padding=12,0, FontSize=12.5`
- 行为不变：`SelectAllOutput_Click → ToggleSelectAll`，点一次全选、再点全不选，文案在"全选/全不选"间切换

### 3. 版本号统一 v1.05r
- **MainWindow.xaml**：`Title`、标题栏 TextBlock → v1.05r
- **App.xaml.cs**：托盘 `NotifyIcon.Text` → v1.05r
- **QuickPanelWindow.xaml**：面板角落 → v1.05r
- **L10n.cs**：`App.About` 8 语言 → v1.05r

## 构建
```
dotnet build SonicRoute.sln -c Debug
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist\pub-single   # 单文件 exe
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:DebugType=None -o dist\pub-dir       # 完整目录 zip
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -o dist\pub-lite  # Lite exe
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained false -p:DebugType=None -o dist\pub-lite-dir # Lite zip
```
