# SonicRoute v1.0.7 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物，commit `5b53599`）。相对 v1.0.6 的改动点如下（含 v1.0.7a 测试期全部功能，正式发布验证通过）。

## v1.0.7 改动点

### 1. 新增：实验模式（隐藏功能）
- **解锁入口**：设置页底部点击作者名「困困困」5 次 → 右上角 OSD 提示进度/解锁成功，持久化 `ExperimentalUnlocked`；解锁后「开机自启」栏下方出现「实验模式」开关（`ExperimentalMode`，开启后重启生效，导航出现「实验设置」）
- 涉及文件：`ConfigService.cs`（+3 字段）、`MainWindow.xaml/.cs`（解锁点击/实验开关/实验设置导航）、`TrayWheelService.cs`（OSD 提示）、`L10n.cs`

### 2. 实验设置页重构 + 麦克风选项
- 导航「设置」下方新增「🧪 实验设置」页，实验模式开启才显示；关闭实验模式入口隐藏、功能不加载
- **麦克风选项**（`ExperimentalMic`，重启生效）：开启后概览 / 快速面板 / 应用 / 设置 均显示麦克风（输入）相关选项，与输出完全对称：
  - 概览：新增输入设备卡片（下拉 + 快捷切换按钮 + 当前显示）
  - 应用：新增输入设备下拉（即选即生效）
  - 设置：保留的设备新增输入勾选区（`HiddenInputDevices`）、设备名称新增输入名称编辑（`DeviceNames` 含输入）
  - 快速面板：新增输入设备区（受实验子选项「在快捷面板显示麦克风」`MicInPanel` 控制）
- 快捷键页「切换当前应用麦克风设备」（`Act.SwitchInput`，默认 `Ctrl+Alt+Shift+D`）仅实验模式 + 麦克风选项开启时显示并注册
- 涉及文件：`ConfigService.cs`（+4 字段）、`HotkeyActions.cs`、`App.xaml.cs`（快捷键过滤）、`MainWindow.xaml/.cs`（导航/实验设置页/概览与应用输入设备/设置页折叠与输入名称/快捷键过滤）、`QuickPanelWindow.xaml/.cs`（输入设备区）、`L10n.cs`

### 3. 自由调整 OSD 显示位置
- 位置下拉（9 宫格 TL/T/TR/L/C/R/BL/B/BR + 「自定义」项 `OsdPosition`）；非自定义时 X/Y 偏移滑块微调（`OsdOffsetX/Y`）；选择「自定义」显示 **X/Y 屏幕坐标输入框**（`OsdCustomX/Y`，输入即保存，通知按坐标直接定位，未设置回退右上角）；保留「↺ 一键还原 OSD 位置」
- 涉及文件：`MainWindow.xaml/.cs`、`TrayWheelService.cs`（`RepositionOsd` / Custom 分支）、`L10n.cs`

### 4. 折叠设置页设备区块（非实验功能）
- 折叠开关最终位于**设置页「启动选项 + 关于」栏**（`ExpCollapseCheck`，开机自启 / 最小化启动 / 启动显示面板之后），**默认开启**（`CollapseDeviceSections = true`），不依赖实验模式 / 解锁；「保留的设备 / 设备名称」（含麦克风）默认收起、可点击标题右侧按钮折叠/展开，切换即时生效（`ApplyCollapseUi()`）
- 涉及文件：`ConfigService.cs`（默认值 true）、`MainWindow.xaml/.cs`、`L10n.cs`

### 5. 实验设置「关闭 UI 释放内存」
- `FreeUIMemoryOnClose`（默认关闭，实时生效）：开启后**关闭完整界面时真正关闭窗口**（不再最小化到托盘，`OnClosing` 分支），触发 App 置空引用并延迟一次 `GC.Collect()` 回收窗口与 UI 内存；下次从托盘打开重建窗口
- 涉及文件：`ConfigService.cs`（+1 字段）、`MainWindow.xaml/.cs`（开关 + OnClosing 分支）、`App.xaml.cs`（Closed 后 GC）、`L10n.cs`

### 6. 其他
- 实验设置「重启生效」提示统一改为「部分功能可能重启生效」
- 版本号统一为 v1.0.7（托盘 / 完整界面 / 快捷面板 / L10n 8 语言 App.About）
- 规范新增「MSI / MSIX 安装包制作规范」章节；目录结构示意补充 `安装包\` 子目录
