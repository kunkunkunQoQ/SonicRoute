# SonicRoute v1.0.5r2 源码说明（带注释）

> 本目录是该版本完整源码快照（已排除 bin/obj 编译产物）。相对 v1.0.5r 的改动点如下。

## 版本命名规范
- 后缀 `a` = 测试版（不上传 GitHub，不归档）；`r` = 修复 bug 后的正式版本（再次修复递增 `r2`、`r3`…）
- **GitHub Release 更新日志只展示最新版本**（含 `r` 修复版）；完整历史日志记录在根目录 README 与 `SonicRoute源码\README.md`

## v1.0.5r2 改动点

### 1. 修复设置页"保留的设备"全选按钮的打勾符号
- **L10n.cs**：8 种语言的 `St.SelectAll` / `St.ClearAll` 文案去掉 "☑" / "☐" 前缀符号（如 "☑ 全选" → "全选"、"☐ 取消全选" → "取消全选"），改为纯文字
- 根因：上一版把全选按钮改为强调色按键，但按钮文本仍带勾选框符号，观感仍是"打勾"

### 2. 完整界面支持点击任务栏图标最小化
- **MainWindow.xaml.cs**：
  - 构造函数订阅 `SourceInitialized`（自绘边框窗口 `WindowStyle=None` 默认点击任务栏不最小化）
  - `MainWindow_SourceInitialized`：获取窗口句柄，检查并补上 `WS_MINIMIZEBOX`（0x20000）窗口样式（`GetWindowLong`/`SetWindowLong`）
  - `TaskbarMinimizeWndProc`：`HwndSource.AddHook` 拦截 `WM_SYSCOMMAND (0x0112)`，当 `wParam & 0xFFF0 == SC_MINIMIZE (0xF020)`（即点击任务栏按钮发出的最小化命令）时手动 `WindowState = Minimized`
  - P/Invoke：`user32.dll` 的 `GetWindowLong` / `SetWindowLong`
- 效果：完整界面打开时，点击任务栏图标即可最小化窗口，无需点窗口右上角最小化按钮

### 3. 版本号统一 v1.05r2
- **MainWindow.xaml**：`Title`、标题栏 TextBlock → v1.05r2
- **App.xaml.cs**：托盘 `NotifyIcon.Text` → v1.05r2
- **QuickPanelWindow.xaml**：面板角落 → v1.05r2
- **L10n.cs**：`App.About` 8 语言 → v1.05r2

## 构建
```
dotnet build SonicRoute.sln -c Debug
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=None -o dist\pub-single   # 单文件 exe
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained true -p:DebugType=None -o dist\pub-dir       # 完整目录 zip
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -o dist\pub-lite  # Lite exe
dotnet publish SonicRoute\SonicRoute.csproj -c Release -r win-x64 --self-contained false -p:DebugType=None -o dist\pub-lite-dir # Lite zip
```
