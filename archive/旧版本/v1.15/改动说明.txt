音跃 SonicRoute v1.15 改动说明（相对 v1.14 正式版）
======================================================

一、多语言体系重构
- 语言数据按语言独立 JSON 文件（内置 9 语言：简中 / 繁中(港澳台综合单版) / 英 / 日 / 韩 / 法 / 德 / 西 / 俄），
  只加载当前语言 + 简体中文回退表
- 切换 / 导入语言即时生效（无需重启），首次启动跟随系统语言
- 实验设置「导入语言」支持外置语言文件（%LocalAppData%\SonicRoute\Lang\），导出内置语言 JSON 可编辑分享
- 自定义语言：文件内 Lang.NativeName 指定显示名；Lang.Custom 非空 = 独立附加语言（不覆盖内置 9 语言）
- 语言栏移至设置底部，卡片排版优化（打开语言文件夹 / 还原默认语言 / 按钮与下拉同行）

二、OSD 首次显示修复
- 首次显示改为「先定位再 Show」：启动后第一次触发带 OSD 的操作（快捷键 / 托盘滚轮调音量），
  OSD 直接出现在正确位置，不再先从屏幕中央闪一下再跳右上角

三、快速面板屏幕定位优化
- 共享 QuickPanelPosition 位置逻辑、合并重复定位请求、工作区 / DPI 变化监听
- 展开收起折叠不再导致面板窗口跳动，自定义位置保持用户设定

四、设置 UI 迭代
- 启动选项独立栏：开机自启 / 启动时最小化 / 启动显示快速面板（含清理自启项，仅绿色版）
- 折叠设备区块选项移至设置并默认开（实验设置不再显示）
- 主题页新增快速面板位置拖拽调整（与 OSD 位置调整逻辑一致，含一键还原）

五、开发过程说明
- 内存回收 / 托盘滚轮系列优化曾多轮实验（含 TrimWorkingSet 温和修剪、图标矩形缓存等），
  最终决定整体回滚到 12:35 提交 + 语言系统的状态，功能表现与 v1.15 开发期一致
- 语言系统 5 项代码审查（统一索引扫描 / 覆盖率剔除特殊键 / 大小写统一 / 禁止 # 内部码 / 未知 code 兜底）已全部落实
