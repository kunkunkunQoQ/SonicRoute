音跃 SonicRoute v1.16 正式版 备份说明
======================================

备份时间：2026-09-14
版本：v1.16（csproj <Version>1.16，FileVersion 1.16.0.0）
构建状态：Release 0 警告 0 错误；Lite / 含运行环境版均单进程启动正常
相对基准：v1.15 正式版（单进程）

一、v1.16 新增：极简自动化规则
- 设置 → 自动化页（位于设置之后、实验设置之前；实验设置仍 Collapsed 门控）
- 规则：名称 + 触发方式（按下快捷键 / 打开应用 / 切换应用）+ 一个或多个操作
- 操作分类：音频控制（切换系统播放/录音设备、调整系统音量、系统静音/取消静音）、
  应用控制（调整应用音量、应用静音/取消静音、切换应用播放/录音设备）、
  高级操作（启动程序、运行 PowerShell 脚本）
- 多操作顺序执行（AutoRule.Actions，List<AutoRuleStep>）；旧单操作字段兼容回退
- 多路径：启动程序 / PowerShell 支持多条路径；路径输入框与「＋ 添加路径」按钮均
  支持拖拽文件自动追加（多选全加、去重）；提示"可拖拽文件到此处"
- 目标应用 / 设备下拉框显示设置页自定义名称
- 规则列表行快捷键以主题强调色加粗显示；快捷键捕获按钮同风格
- 文本精简 9 语言同步；删除提权提示；新增 AddAction/AddPath/DragHint 键

二、其他改动
- 快速面板（经典 + 简洁）启动滑入动画：TranslateTransform.Y 12px→0，180ms
  QuadraticEase 缓出，仅内容就绪定位后播放一次，SizeChanged/折叠不重放
- 修复自动化切换操作下拉框崩溃（WPF Children[i] 不支持替换已占用索引）
- en-US JSON 转义引号损坏行修补
