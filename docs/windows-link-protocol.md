# Windows Link v1

Windows Link is opt-in in Full. The connection and stream code lives in `SonicRoute.AndroidAudio/WindowsLink` so it can reuse the media code that Full already ships. Each peer can send and receive at the same time. The protocol runs over one mutually authenticated TLS TCP connection per peer. The listener defaults to TCP 46916. IPv4 LAN discovery uses UDP 46917 and is a hint only. A manual IP can include a port.

Each peer has a private certificate in user-protected local state. Its ID is the SHA-256 of the leaf DER certificate. The TLS handshake verifies possession. Previously trusted IDs are pinned. New peers exchange randomness with a commitment before revelation, compare the resulting eight-digit code on both computers, and both explicitly confirm. An advertised address cannot establish trust. Pairing attempts and unauthenticated connections have bounded counts and deadlines. If both peers dial at once, the connection initiated by the lower ID wins. An established connection stays in use unless an overlapping dial must be resolved.

Manual reconnect can use the existing IPv4 discovery port to ask a saved peer to dial back when direct TCP attempts fail. The request includes the recipient's certificate ID, the sender's listening TCP port and the issue time, signed by the sender's existing identity. The recipient checks its pin and the signature, rejects stale requests, and rate limits requests for each saved peer. It then dials the LAN source address and requires the same pinned identity over mutual TLS. Older peers ignore this request.

Once authenticated, a frame starts with a one-byte type, a 16-byte stream GUID in .NET byte order, and a four-byte, little-endian payload length. Control and audio have priority between bounded video fragments. Per-peer queues and per-stream receiver buffers are bounded. An open message declares the stream kind, title, and whether the sender allows input. Streams are owned by their creator and close on disconnect or explicit stop by either side. Audio v1 is stereo 48 kHz signed little-endian PCM16. Video v1 is H.264 Annex B, with a little-endian microsecond timestamp and fragment flags. Video options are per stream. Input and volume messages apply only to the matching stream. Window input requires affirmative consent on the sender for that stream and only targets its shared source window.

`WindowsLinkService` owns start, stop, discovery, trust, connection and stream state. UI code reads peer and stream snapshots and dispatches notifications onto the UI thread. Media adapters receive only selected local process IDs, window handles, PCM or video frames. They have no network protocol or UI dependencies. Media resources exist only while their streams are active. Transport priority, cancellation and limits live in the connection layer.

The audio catalog request uses the sender's cached Windows audio-session enumeration. It skips window discovery and reports whether an app has an audio session independently of whether it is playing. The sender excludes local quick-panel hidden apps from the catalogs. On a visibility change it sends an empty catalog invalidation to compatible peers. An open quick panel clears its snapshots and reloads only the visible view.

Existing WASAPI process loopback supplies system audio by excluding SonicRoute's process tree and app audio by including the selected process tree. This requires Windows build 20348 or later. Receive-side playback reuses the existing PCM ring and WASAPI output. Window capture uses Windows Graphics Capture. The Media Foundation encoder complements the existing H.264 decoder and Direct3D renderer. No custom driver or new codec package is required.

When both peers advertise audio readiness, the receiver replies after its playback consumes incoming PCM or reports an initialization failure. The sender publishes the active route after that reply. A destination-only app stream then acquires the shared local silence lease, which reads and restores the multimedia and console endpoint routes through Windows audio policy. A window share has its own stream lifetime.
