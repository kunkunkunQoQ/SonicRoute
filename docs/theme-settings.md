# v1.21：主题与设置界面

本页记录 v1.21 已发布版本的主题与设置界面改进。阶段检查、数据和限制均为对应阶段的历史记录，不代表对所有阶段做了统一的重新测试。

## 主题色与模式

跟随系统、浅色、深色控制界面明暗。“主题色”是唯一的强调色编辑区域，提供色块、六位 Hex 输入、选择颜色按钮和静态矢量预览。

- Hex 可以带 `#`；按 Enter 或离开输入框时应用，Esc 恢复。无效输入恢复当前值并提示。
- “选择颜色”打开与主题一致的新选色窗口，提供 96 个基本颜色、完整彩虹色谱、右侧明暗条和精确 Hex / RGB / 色相 / 饱和度 / 亮度输入。没有自定义颜色收藏区、定义或添加按钮；确认后应用，取消不改变主题。
- 色谱横向选择色相、纵向选择饱和度；明暗条独立调整亮度。色相范围 0–360°，饱和度与亮度为 0–100%，支持小数。色谱支持拖动和方向键，明暗条支持原生滑块操作。
- 蓝色、绿色、粉色预设按钮及高级颜色设置已移除。原有预设配置仍显示原颜色，无须重设。
- 高级颜色入口、RGB 滑块、专用事件及预览计时器已删除。RGB 反色、禁用图标、深浅模式对比色与其他颜色计算保留。
- 静态预览引用共享主题画刷，没有常驻刷新。颜色即时应用，沿用 200 ms 延迟保存；窗口关闭时保存待写入值。

## 透明度、OSD 与面板

背景透明度沿用原范围及保存逻辑。

OSD 外观和快速面板位置使用相同的图标标题、右侧位置按钮、分隔线及三列参数行，布局对应“标签 / 滑块 / 数值”。OSD 保留音量进度条、麦克风静音常驻、宽度、字号及淡入淡出设置；“更多选项”统一展开参数和监听子项，监听子项仅在常驻开启时显示。

OSD 还原按钮简为“还原位置”。位置按钮保留独立的大图标，文字前的重复小符号已移除。

“经典面板”改名为“应用面板”，“简洁面板”改名为“快捷面板”。面板高度仍为 350–800，默认 450；实时声音活动开关与原有排除、采样逻辑保留。配置中的 `classic` / `modern` 标识没有改变，旧配置继续使用。

自动化步骤延时输入与启动模式左对齐，执行逻辑不变。

## 设置页

保留设备使用勾选卡片。设备名称行左侧显示原始名称，右侧编辑自定义名称；右侧 × 已移除，手动删空名称可恢复默认名称。输出、输入和系统默认设备共用构造方法。

最近使用、上次操作和指定应用沿用原选择逻辑。杂项整行开关共用样式；麦克风提示缩短为“启用输入设备设置与切换快捷键。”

首次打开设置时，内部只用于显示的开关会冒泡状态事件。设置处理器现在只接收外层设置自身的事件，避免首次加载触发实验提示、重复保存或自启动操作。语言下拉重建也会恢复外层事件抑制状态。

保留设备和设备名称的行在进入设置且对应区域展开后才创建；启用设备区域折叠时，折叠状态不会提前创建这些行。已创建且未变化的行继续复用，设备或界面语言变化后，下次显示时更新。关闭折叠功能时，进入设置即创建可见行。应用候选列表与其他页面共用数据，选中项仍各自独立。

## 统一输入框

所有应用内文本输入共用新的圆角、主题边框、焦点和禁用样式，包括设备名称、主题色、搜索、自动化名称/路径/OSD/延时及语言编辑。搜索框在同一模板上增加图标和占位文字；旧的独立搜索模板和设备名称外层重复边框已删除。

共用模板保留 WPF 原生编辑宿主，已有字段保存、输入校验、拖放事件和只读属性继续使用。输入装饰不添加定时器。

## 构建与体验

阶段 45 提供 Lite x64、Legacy x64 开发构建及 ARM64 编译。Lite 和 Legacy 分别通过 40 项隔离检查，覆盖名称保存与清空恢复、首次设置无实验提示、Hex/RGB/HSL 校验、完整彩虹色谱选色、明暗端点、选色确认/取消、搜索选择/撤销/重做、自动化参数和延时写回、多行及只读输入，并检查深浅模式截图。实际配置与规则文件前后校验一致。

阶段 46 为延迟创建设备行、释放已结束的编辑器、共享下拉数据和默认规则名补充了 Lite / Legacy 各 34 项隔离检查。实际进程内存与 CPU 占用尚未重新采样。

阶段 47 完成关闭资源清理，并重新进行隔离内存测量。关闭时退订常驻事件，停止窗口计时器与动画，解绑动态列表和编辑器；取消旧窗口的读取等待和排队更新，已提交操作继续完成，快速面板待提交的音量快照会写完。生产程序不再主动强制 GC；窗口关闭后延迟 1.5 秒执行空闲工作集整理，重开时会取消整理。整理会将不活跃页面移出工作集，不代表私有提交内存释放；重开时系统可能重新读入页面。本机隔离发布版稳定后台的私有工作集为 4.52–5.80 MiB，私有提交约 119 MiB；这是本机测试结果，不保证在每台设备或每种负载下重现。Lite 与 Legacy 各通过 30 项关闭检查、34 项回归检查及 1 项回归汇总；Lite x64 发布、Legacy x64 Release 构建和 Lite ARM64 编译均为 0 错误。ARM64 仅编译，未做真机运行。阶段 46 的历史检查仍未采样实际进程内存与 CPU；阶段 47 的独立测量补充了关闭后的内存数据，不表示对阶段 43 报告的重新测量。

ARM64 未做真机运行。阶段 45–46 未模拟输入法组合输入或重跑资源采样；阶段 47 的测量范围与局限如上，不代表重新测量阶段 43 的完整性能报告。

退出旧实例后打开新版，建议依次查看主题色编辑、OSD 更多选项、面板位置/高度、首次进入设置及设备名称编辑。原名称可通过清空输入框恢复。

## 后台检查与应用名称（v1.21，阶段49）

实验设置新增“后台定时检查兜底”，默认关闭，切换后立即生效。关闭时，前台应用和麦克风状态正常依靠通知更新；没有匹配到音频时短暂重试，发现监听故障时临时检查并恢复，恢复成功后停止检查。开启后持续保留前台1.5秒和麦克风2秒检查，适合通知兼容性不佳的环境。自动化规则及其它功能的计时器仍按原策略运行。

主界面与两种快速面板顶部统一显示 `SonicRoute`，保留版本号。应用图标使用新的透明耳机图案，托盘随系统任务栏主题采用黑色或白色轮廓。商店包补齐无底板图标资源及索引；商店用户可从 [Microsoft Store](https://apps.microsoft.com/detail/9NQZGRTPM1NT) 获取上架版本。
