# 🎧 SonicRoute v1.30 正式版

> **发布日期**：2026-11-04 · **主题**：Full 增加可选 Android 手机音频集成与独立虚拟屏幕 · [📥 发布页](https://github.com/kunkunkunQoQ/SonicRoute/releases/tag/v1.30) · [📖 使用指南](https://github.com/kunkunkunQoQ/SonicRoute/wiki/01-%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97)

## ✨ 更新亮点

- 📱 **Full 加入可选手机集成**：连接 Android 手机后，可把手机应用声音接入电脑，按应用调节音量、静音和输出，也可将电脑应用声音送到手机。手机功能只包含在 Full；Lite 与 Legacy 保持 PC 音频功能，不带手机集成。
- 🖥️ **手机应用独立虚拟屏幕**：可将手机应用画面显示在电脑窗口中，并按手机与应用保存窗口对应的虚拟分辨率；窗口尺寸变化会调整虚拟显示尺寸。
- 🔊 **手机音频输出明确受控**：手机应用流转到电脑后，扬声器与已连接蓝牙输出均保留在 SonicRoute 控制下；电脑音频送往手机时，也会确认实际目标输出，避免把“请求成功”误当成路由已切换。
- 📊 **快速面板显示手机应用峰值电平**：可见的手机应用行复用实时电平条；关闭面板或禁用电平表会停止对应采样订阅。
- 🧭 **手机设备与固定应用管理**：手机设备可独立管理，固定应用会显示在手机快速面板；智能音量默认开启，可按应用关闭。

## 🛠️ 详细更新

### Full 手机集成

- 在 Full 中加入 Android 设备连接、手机应用目录、按应用音频流转、手机输出选择及独立虚拟显示。使用手机功能需要 Android 调试连接；手机侧音频帮助组件按需使用。
- 手机应用沿用 SonicRoute 的音量、静音和输出操作；切换到手机扬声器或蓝牙设备仍由电脑侧控制，退出流转后才交还手机自身播放。
- 手机应用和电脑应用的音频路径相互隔离。手机流不会伪装成 Windows 进程或录音会话；没有可用的 Windows 输入会话时，输入操作保持不可用。
- Lite 与 Legacy 不包含手机 UI、手机音频实现或手机运行依赖。Microsoft Store 的安装包以 Full 为构建来源，但商店当前在架版本及上架时间以 [Store 页面](https://apps.microsoft.com/detail/9NQZGRTPM1NT)为准。

### 手机路由与快速面板

- 手机应用行显示峰值电平条。采样复用现有可见行采样服务，手机流的 PCM 写入只在采样器等待时触发合并唤醒；这项机制不等同于整版 CPU 或内存降幅。
- 设备页固定应用直接显示在手机快速面板。智能音量默认开启，可逐应用切换；手机输出列表只提供该源手机可用的扬声器和已连接蓝牙输出。
- 全部音频路由、输出切换与退出操作保持按应用隔离。切换输出时验证实际设备路由；未确认时不会把成功提交设置当作声音已切换的证据。

### 自动化与桌面版维护

- 自动化支持 6 类触发与 39 项动作。
- Lite 与 Legacy 延续 v1.29 的轻量工作集回收策略。本版没有量化整版 CPU、内存或窗口响应提升，不据此推断长时间使用或不同设备上的性能变化。

## 📋 验证范围与限制

- 开发阶段记录了 118 项定向检查，其中小米 13 真机检查覆盖扬声器与蓝牙切换、非静音 Opus/PCM 数据和受控退出。这是开发阶段证据，不表示这些检查均在本次正式候选包上重跑，也不代表所有 Android 机型、系统版本或音频设备均已验证。
- 真机验证覆盖了指定的手机应用和测试路径；人工听感、长时间 CPU/内存测量、原生 ARM64 设备及其他 Android 设备仍未验收。微软商店安装后的行为取决于当前商店在架版本，不能由便携版测试替代。
- 定向读取或通知合并检查只证明对应路径行为，不构成整版性能提升数据。自动化 39 项动作数量来自当前源码枚举。

## 🔄 升级与数据保留

升级前请从托盘正常退出 SonicRoute。替换单 EXE 或完整解压 Legacy ZIP 时，选择对应发行形态与架构；升级器不会跨发行形态或运行时迁移。设置、自动化规则、主题和自定义图标保存在数据目录中，手动升级前可按需备份 `%LocalAppData%\SonicRoute\`。Store 版继续通过 Microsoft Store 更新。
