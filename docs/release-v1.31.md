## ✨ 更新亮点

- 🏷️ **多语言友好编码器名称与硬件在线检测**：手机详情页 Opus 与 H.264 编码器选择器升级为可读友好说明（“厂商 · 硬件/软件编码 (原ID)”），支持 Android 29+ 编解码器真实能力实时查询与离线厂商前缀兜底，硬件优先排序与长文本悬停提示，九语即时刷新。
- ⚡ **更高画质码率与 120 fps 高帧率选项**：画面 H.264 码率预设扩展为 `[1, 4, 6, 8, 12, 16, 24, 32, 50] Mbps`（移除 2 Mbps）；画面帧率预设扩展支持 `120 fps`（`[15, 24, 30, 60, 120] fps`）；520 DIP 窄布局优化确保下拉选项完整无截断。
- 🖥️ **整机主屏镜像恢复与等比缩放**：整机卡片拖出恢复使用 `display0` 等比缩放镜像手机主屏，接管整机音频，复用 GPU D3D11 渲染，原生窗口统一复用手机轮廓图标且标题栏仅显示手机设备名称。
- 📋 **多设备双向文本剪贴板同步**：支持电脑与已连接 Android 手机之间的文本剪贴板按需同步，每台设备独立开关持久化（`phone-clipboard.json`），上限 64KiB，版本校验抑制回传环路，无后台空转轮询。
- 🌐 **九语全面本地化与设置页稳定性修复**：九种内置语言补齐至 838 键并支持已打开界面热切换；修复设置页特定控件默认双向绑定写回只读索引器导致的闪退问题。
- 🚀 **音频起音低延迟与交互体验打磨**：手机端渲染起步门槛优化为 20ms PCM 帧，重叠握手与传输准备，显著降低起音延迟；手机面板在拖拽期间显示“返回手机播放 / 松开后，由手机控制声音”卡片；手机 stderr 持续排空并限额最近 16,384 字符缓冲；自动化刷新复用单批过滤候选集以减少临时分配。

## 🛠️ 详细更新

### 1. 友好编码器名称、码率与 120 fps 支持

- 将手机详情页直接暴露的裸 Android Codec ID 替换为可读友好说明（如中文 `高通 · 硬件编码 (c2.qti.avc.encoder)`、`Android · 软件编码 (c2.android.avc.encoder)`），并在括号中保留原始 ID 以保持配置持久化与底层命令参数兼容。
- 实时通过 `EncoderCatalog` 查询 Android 29+ 的真实软硬件编解码能力，离线展示时基于高通、联发科、三星 Exynos、海思、紫光展锐等厂商前缀表安全兜底；编码器列表按硬件优先排序，下拉框文本过长时使用省略号并在悬停时实时展示完整说明。
- 画面码率移除 `2 Mbps`，增加 `24/32/50 Mbps`；画面帧率增加 `120 fps`。整机主屏镜像与单应用虚拟屏均支持全码率与高帧率透传；第三列预设在 520 DIP 窄窗口下保证不被截断。

### 2. 整机主屏镜像恢复与多设备剪贴板同步

- 手机整机卡片拖出恢复为镜像当前手机主屏（`display0`），画面保持原比例缩放并接管整机声音，全屏快捷键在镜像模式下自动转为等比最大化/恢复。
- Scrcpy 原生客户端程序图标及窗口/任务栏图标统一复用手机轮廓矢量资源，标题栏仅保留手机设备名称。
- 支持 PC 与 Android 手机双向剪贴板同步，在手机详情页以动态开关独立控制；开启后仅注册系统剪贴板变化通知，发送内容上限 64KiB UTF-8，支持换行与表情符号，停用或离线后自动注销监听。

### 3. 音频起音低延迟、拖拽返回提示与长效优化

- 优化手机端 `AudioOutputBridge` 播放策略：将 `AudioTrack` 启动门槛设为 20ms PCM 缓冲，音频传输与端口建立并行推进，重叠手机端渲染准备，减少初次发声与设备切换延迟。
- 手机音频面板在整个应用拖拽期间显示“返回手机播放 / 松开后，由手机控制声音”主题卡片，松开即可交还手机原生播放。
- 手机 helper 进程 stderr 输出从无限累积改为持续排空并仅保留最近 16,384 字符，长时间运行不再造成内存持续增长。
- 自动化规则编辑器单次刷新共用已过滤应用候选集合，避免多个步骤选择器重复扫描与分配。

### 4. 全语种本地化完善与设置页防闪退

- 全面补充九种内置语言（简中、繁中、英文、日文、韩文、法文、德文、西班牙文、俄文）至 838 键，包含 58 种稳定错误标识。
- 修复点击主界面「设置」时因开源许可文本默认双向绑定写回只读本地化索引器导致的程序崩溃闪退问题。
- 已打开的主窗口、手机详情页、音频面板、快速面板及虚拟屏状态窗均订阅语言变更通知并原地刷新，无需重新连接手机或重启软件。

## 📋 验证范围与限制

- 经由 670 项离线定向检查、真机（小米 13）编码器与主屏镜像验证、九语资源与运行时清单检查、Full/Lite/Legacy 三版本编译及 Full x64 ReadyToRun 独立发布校验通过。
- 本版便携附件发布 Full x64、Lite x64 与 Legacy x64；ARM64 便携版暂未随本版附带，ARM64 用户可继续使用 v1.30 或通过 x64 兼容层运行。
- 定向起音延迟改善记录了开发机与指定测试设备的实测中位数，不代表所有 Android 机型或蓝牙耳机均能达到相同效果；真实 120fps/50Mbps 流媒体表现受 Wi-Fi 信号质量与手机芯片编解码能力制约。
