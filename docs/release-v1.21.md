# SonicRoute v1.21 正式版

2026-10-09 · [GitHub Release](https://github.com/kunkunkunQoQ/SonicRoute/releases/tag/v1.21)

本版更新完整界面与自动化编辑体验，改进关闭窗口后的资源清理，采用事件通知跟随前台应用和麦克风静音，并更换透明耳机图标。

## 下载与升级

| --- | --- | --- |

| Lite ARM64（实验） | [单 EXE](https://github.com/kunkunkunQoQ/SonicRoute/releases/download/v1.21/SonicRoute-v1.21-Lite-arm64.exe) | ARM64 .NET 8 Desktop Runtime，尚未完成真机完整验证 |

支持 Windows 10 2004+ / Windows 11。升级前正常退出旧实例，再运行新版；设置与规则沿用原数据目录。也可通过 [Microsoft Store](https://apps.microsoft.com/detail/9NQZGRTPM1NT) 安装和更新。

## 主要变化

- **界面与设置**：统一导航、卡片、开关和文本输入样式；改进深浅主题、Hex/RGB/HSL 颜色编辑与选色，设备名称可编辑、清空后恢复原名称。主界面及两种快速面板顶部统一显示 `SonicRoute` 并保留版本。
- **自动化编辑**：规则卡片显示真实名称、操作和触发摘要；保留搜索/筛选与滚动位置；支持展示顺序拖动，编辑器布局更清楚。名称留空时自动选择可用的“规则1”“规则2”……，手动名称保留。
- **常用操作**：复制规则执行命令、托盘常用规则、音量滑块右键 25% / 50% / 75% / 100% 档位。
- **规则执行**：新增“执行另一条规则”，等待目标完成，并防止自身调用、循环和过深调用；每步新增可选“失败后停止”，默认关闭。命令行结果增加 `Stopped`、`Skipped`，原退出码含义保留。
- **关闭资源**：主窗口与两种快速面板关闭时退订、解绑并取消尚未提交的界面读取/更新，已提交操作继续完成。程序不主动调用强制 GC；工作集整理仍保留。
- **前台与麦克风**：前台事件及时更新目标，静音与设备通知更新麦克风状态；没有匹配到音频时短期重试，可检测故障时临时检查并恢复监听。
- **兼容性开关**：实验设置新增“后台定时检查兜底”，默认关闭、立即生效；开启可恢复持续的前台 1.5 秒与麦克风 2 秒检查。设备通知与异常恢复持续保留。
- **其它后台工作**：鼠标绑定按需监听、隐藏/最小化暂停候选刷新、指定进程存活句柄复用、规则文件变动通知和缓存修订，减少重复查询与控件创建。
- **新图标**：采用新的透明耳机图案，应用资源为 256×256 PNG 和多尺寸 ICO；托盘随任务栏主题使用黑色或白色轮廓。商店打包脚本补齐无底板主题图标与资源索引，修复导致图标底板的打包配置。

## 验证与适用边界

Lite、Legacy 各 144 项功能检查通过；另各有 34 项实际主面板目标检查。真实双前台目标普通切换 12/12 正确，密集切换最终目标正确。两版及 ARM64 构建无错误；ARM64 仅编译和包结构检查，未完成真机运行验证。

本机同源码隔离发布构建关闭窗口后，稳定后台总工作集为 11.24–16.61 MiB，私有提交均值约 114.91 MiB。工作集整理不等于释放私有提交；这些是本机测试结果，不保证所有设备低于 30 MB。周期状态查询停止已验证，整体 CPU 降低尚未得到实测支持。

正常事件监听并不能保证每款驱动都不丢通知；静默丢失未必能被自动发现，遇到兼容性问题可开启实验兜底。音频会话超过短期重试窗口才出现时，需要下一次前台、手动或设置刷新触发。自动化、电平与规则目录恢复仍保留各自必要的定时任务。

详细使用方法见 [Wiki](https://github.com/kunkunkunQoQ/SonicRoute/wiki)、[主题与设置](theme-settings.md) 和 [自动化说明](automation-convenience.md)。源码和可复现检查保存在本仓库历史归档中。
