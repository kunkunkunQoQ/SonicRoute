# Windows Link

两台 Windows 电脑各运行同一份 SonicRoute Full。在「应用 → 添加设备」中，从 Android、AirPlay 和 Windows Link 里选择 **Windows Link**。快捷设备面板底部的设备下拉也能进入同一功能。两端启用后，同一局域网内会出现设备。也可以输入对方显示的 IP 和端口，默认 TCP 46916。系统防火墙提示时，允许应用在所用的私有网络通信。局域网搜索使用 UDP 46917。

选中对方设备连接。第一次连接时，在两台电脑上核对同一个八位码，再分别确认。配对后的电脑出现在应用页设备侧栏和快捷设备下拉。快捷下拉先列出设备，最后两项固定为 AirPlay、Windows Link。

在快捷设备面板选中已配对电脑后，顶部可切换「音量」和「窗口」，下方搜索框只筛选当前列表。双击或按 Enter 可接收所选应用的音频，或打开所选窗口。「应用」页的设备设置可重命名、断开和移除配对。异常掉线会尝试恢复，主动断开会暂停重试。关闭 Windows Link 会停止发现和所有流。

已配对的电脑可以从任一端点「重连」。直连失败时会重新查找对方地址，并可请求对方反向建立同一条连接。反向重连要求两台电脑都运行支持该功能的版本，并能通过局域网送达发现请求。

- **系统音频**通过音量页底部的「对方电脑的所有声音」接收支持此功能的对端系统声。SonicRoute 自己播放的声音排除在采集外，避免接收端把它再次转发。
- **音量**直接读取对方枚举的 Windows 音频会话。仍保有会话的应用暂停播放时也会列出。发送端关闭应用的「在快速面板显示」后，该应用从互联的音量和窗口列表隐藏，两端使用新版时会刷新已打开的面板。在两台电脑之间拖动应用图标时，上半区为仅目标电脑播放，下半区为两台电脑同时播放。不可用的区域会标明原因。仅目标播放会在接收端确认播放后，将发送端应用临时路由到备用静音端点，结束时恢复仍由此串流占用的端点。发送端只有一个可用端点时，可选同时播放。系统音频使用同时播放。活动串流可单独调音量、静音、选本机输出或停止。
- **窗口**列出对方可共享的应用窗口。双击、按 Enter 或拖到面板外可打开独立窗口，窗口可移动、缩放或关闭。窗口串流和音频串流可分别启动、停止。发送端可允许远程输入，原窗口处于前台时才接收窗口范围内的操作。

音频发送使用 Windows Build 20348 及以上的 WASAPI 进程回环。较旧版本的 Windows 可以接收音频。窗口共享使用 Windows Graphics Capture 和 Media Foundation H.264。部分受保护、最小化或禁止捕获的窗口可能无法提供画面。

协议及依赖说明见 [Windows Link v1](windows-link-protocol.md)。
