# Windows Link

两台 Windows 电脑各运行同一份 SonicRoute Full。在「应用 → 添加设备」中选择 **Windows Link**，或从快捷设备面板底部的设备下拉进入。两端启用后，同一局域网内可通过 UDP 46917 搜索设备。

通过局域网、VPN 或其他可直达网络连接时，可粘贴对方的主机名、IPv4 或 IPv6。省略端口时使用 TCP 46916。自定义端口的示例为 `studio-pc:8443` 和 `[2001:db8::15]:8443`。点击「本机地址」可以复制；本机有多个地址时可按网卡选择，例如 Wi-Fi 或 VPN。连接需要已有网络路由和端口可达。

选中对方设备连接。第一次连接时，在两台电脑上核对同一个八位码，再分别确认。配对后的电脑出现在应用页设备侧栏和快捷设备下拉。快捷下拉先列出设备，最后两项固定为 AirPlay、Windows Link。

在快捷设备面板选中已配对电脑后，顶部可切换「音量」和「窗口」，下方搜索框只筛选当前列表。双击或按 Enter 可接收所选应用的音频，或打开所选窗口。「应用」页的设备设置可重命名、断开和移除配对。异常掉线会尝试恢复，主动断开会暂停重试。关闭 Windows Link 会停止发现和所有流。

已配对的电脑可以从任一端点「重连」。手动拨通的主机名和端口会保存在本机，重连时重新解析名称并验证对方的配对证书。通过端口映射连接的设备会复用外部端口。设备仍可通过局域网发现更新地址；支持反向重连的两端也可通过局域网请求对方回连。

- **系统音频**位于「音量」列表首行。单击「对方电脑的所有声音」可选中，双击或按 Enter 即可收听，也可将该行拖到主面板或右键选择播放目标。SonicRoute 自己播放的声音排除在采集外，避免接收端把它再次转发。
- **音量**直接读取对方枚举的 Windows 音频会话。仍保有会话的应用暂停播放时也会列出。发送端关闭应用的「在快速面板显示」后，该应用从互联的音量和窗口列表隐藏，两端使用新版时会刷新已打开的面板。在两台电脑之间拖动应用图标时，上半区为仅目标电脑播放，下半区为两台电脑同时播放。不可用的区域会标明原因。接收端确认播放后，发送端会为「仅目标播放」选取空闲的非默认输出，按需临时静音，并核实应用实际切换了输出。结束时恢复该应用的原路由和临时调整的静音状态。如果发送端的所有输出本就处于用户静音状态，可以直接采集。发送端只有一个扬声器时，使用新版的两端可以直接拖到上半区，或在右键菜单选择带有「静音来源扬声器」的选项。接收端确认就绪后会暂时静音来源扬声器，远端收到所选应用的声音。此时来源电脑上使用同一扬声器的其他声音也会静音。拖回或断开后，扬声器恢复先前状态。下半区保留两端播放。固定使用原输出的应用会收到切换失败提示。要停止接收，可从本机主面板把应用拖回来源电脑。右键应用行可打开播放菜单选择目标。键盘聚焦该行后也可按菜单键或 Shift+F10。系统音频使用同时播放。活动串流可单独调音量、静音、选本机输出或停止。
- **智能音量**在 Windows 设备详情中自动列出有音频会话的远端应用，包括已暂停的应用。每个应用有一个开关，按设备保存。启用后会压低较响的片段，低电平信号以选定的音量播放。
- **文件**在对方电脑的设备详情中，把文件拖到「文件传输」区域，或点击区域多选文件。多个文件依次发送。普通配对下，接收方点击「接收」即可保存，也可以另存为。本机默认使用 Windows 的「下载」文件夹，可在「本机接收文件夹」旁点击「更改文件夹」；该位置适用于所有 Windows Link 设备。同名文件自动编号，传输中可以取消。
- **完全信任**在两台已配对的电脑上分别打开对方的设备详情，点「生成信任码」，再分别输入对方显示的 8 位码。两端打开的设备页会自动显示对方已生成验证码、等待验证和已启用等状态。双方验证通过后，此设备发送的文件会自动保存，也可以直接操作已共享的窗口和显示器。完全信任会保存到这两台已配对的电脑。关闭软件、重启电脑或断网后再次连接时会自动恢复。任一端都可以关闭完全信任，离线关闭会在下次连接时同步。
- **窗口**列出对方的显示器和可共享的应用窗口。双击、按 Enter 或拖到桌面可打开独立查看器。两端更新后，打开应用窗口会接收该应用的声音，打开显示器会接收对方整机声音。主面板可调节音量。多个查看器使用同一条声音时，关闭最后一个查看器才移除自动加入的声音。先手动拖到主面板的声音在关窗后继续播放。在发送端允许远端键鼠后，可从查看器操作被其他窗口遮挡的共享窗口。在显示器预览中，点击选择要操作的应用，键盘输入随后发给该窗口。SonicRoute 直接把输入投递给应用控件，发送端可继续使用自己的鼠标和键盘。关闭权限立即停止接收后续输入。最小化窗口、依赖原始硬件输入的应用及部分系统快捷键不支持这种控制方式。应用自身弹出对话框时，焦点由应用和 Windows 决定。

每次启用 Windows Link 时，SonicRoute 会检查本机能否初始化 WASAPI 进程回环。通过检查的电脑可以发送应用和系统音频，也可以把已连接且支持接收的电脑选为应用输出。采集不可用时仍可接收声音。两端更新后重新连接即可刷新能力，无需重新配对。窗口共享使用 Windows Graphics Capture。设备详情可单独设置分辨率、帧率、码率、编码器和解码器。两端更新后，在「画面」选择「原生分辨率」，下次拖出的窗口或显示器会按来源像素传输。奇数宽高会裁去最外侧的一列或一行。默认使用 H.264，两端均支持 HEVC 时可选 H.265，相应设置在下次打开窗口时生效。部分受保护、最小化或禁止捕获的窗口可能无法提供画面。

协议及依赖说明见 [Windows Link v1](windows-link-protocol.md)。
