音跃 SonicRoute v1.20 工作区阶段备份（UI 与内存占用优化）

状态：本地开发快照，未上传、未发布；前一阶段快照为 v1.20-02-实时电平-性能优化。

源码：SonicRoute、SonicRoute.Core、SonicRoute.Legacy 三工程及解决方案、README、AI_CONTEXT、图标、.gitignore；排除 bin/obj。包含尚未提交的 AudioMeterService.cs。
可运行版本：Lite-x64 框架依赖单文件（优先测试）；Legacy-x64 Release 多文件运行目录，不含 pdb。

本阶段改动：
1. 设备缓存 TTL 单位纠正为 3000ms，修复此前约 8.33 小时的误缓存。
2. 自动化进程快照与全局清理路由的 Process 对象及时 Dispose；自动化 Watcher Tick 单飞、后台进程枚举、重启代际防旧快照覆盖。
3. 主题冻结画刷缓存上限 256；自定义 RGB 33ms 合并预览、200ms 防抖保存，关闭窗口补存；透明度即时预览。
4. 自动化页 8s 刷新时，仅应用列表变化才重建下拉和图标，异步刷新防重入。
5. 主窗口/快速面板全关后仅一次延迟 GC 与工作集修剪，重开 UI 取消；idle 120s 去重。
6. 会话 COM 枚举单飞，成功完成后才计算 2s 缓存时间，异常时释放本轮已收集的引用。

快速面板实时电平采样范围维持前一阶段：隐藏、静音或无可用滑块的应用不采样，滚出屏幕的应用仍采样；未做 UI 虚拟化。
构建：Lite x64 Release 单文件发布成功；Legacy Release 0 错误，47 条既有可空性警告（最终增量构建显示 42 条）。未做运行时内存/交互实测。
